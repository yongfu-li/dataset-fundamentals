    🎯 Conceptual Overview & Joint Dependency Modeling

    A catastrophic failure mode in tabular synthetic data generation is treating multi-variate features as statistically independent random variables. When each attribute is synthesized independently via isolated univariate estimators, the generator produces synthetically plausible marginal values that are jointly nonsensical: pediatric patients with adult hypertension, high-income executives with zero credit history, or negative asset valuations with elevated implied volatility (Nelsen, 2006). High-utility synthetic datasets require preserving the complete joint dependency structure \(\boldsymbol{\Sigma}\), non-linear rank correlations, and asymptotic tail co-movements across heterogeneous continuous and categorical attributes (Patki et al., 2016; Embrechts et al., 2002).

    To isolate and model multi-dimensional dependencies without distorting individual marginal distributions, statistical pipelines employ Copula Theory grounded in Sklar's Representation Theorem (Sklar, 1959) alongside Non-Parametric Empirical Bootstrapping (Efron, 1979; Efron & Tibshirani, 1994).

    Linear Correlation vs. Rank Association & Tail Dependence

    Traditional statistical pipelines rely heavily on Pearson linear correlation coefficient \(r\). However, for complex real-world data generation, Pearson correlation exhibits severe structural vulnerabilities (Embrechts et al., 2002):

    Property 1 (Non-Invariance to Non-Linear Transformations): Pearson correlation \(r(X_1, X_2)\) changes under strictly monotonic transformations. If \(Y = \exp(X)\), then \(r(X, Y) < 1.0\) despite a deterministic one-to-one functional relationship. In contrast, Spearman's rank correlation \(\rho_s\) and Kendall's tau \(\tau\) measure rank concordance and remain invariant under any strictly increasing monotonic transformation:

    \[ \tau(X_1, X_2) = \mathbb{P}\left((X_{1i} - X_{1j})(X_{2i} - X_{2j}) > 0\right) - \mathbb{P}\left((X_{1i} - X_{1j})(X_{2i} - X_{2j}) < 0\right) \]

    Property 2 (Asymptotic Tail Independence): Two variables can exhibit high overall Pearson correlation (\(r = 0.80\)) while possessing zero lower-tail dependence (\(\lambda_L = 0\)). During extreme drawdown events (e.g., market crashes, systemic server overloads, or compound disease comorbidities), variables exhibiting tail independence decouple, underestimating joint catastrophe risk. Property 3 (Elliptical Symmetry Constraint): Standard Gaussian covariance assumes elliptical symmetry. Asymmetric interactions (e.g., credit defaults clustering strongly during economic downturns but showing diffuse independence during bull markets) cannot be represented by a single linear correlation coefficient.

    🧮 Mathematical Formulations of Copula Synthesis

    Definition 10.4.1 (Copula Function & Fréchet-Hoeffding Bounds)

    A \(d\)-dimensional copula is a multi-variate cumulative distribution function \(C: [0, 1]^d \to [0, 1]\) whose univariate marginal distributions are standard uniform on \([0, 1]\) (Nelsen, 2006). Formally, \(C\) satisfies three axiomatic properties:

    Axiom 1 (Groundedness): For every \(\mathbf{u} = (u_1, \dots, u_d) \in [0, 1]^d\), \(C(\mathbf{u}) = 0\) if at least one coordinate \(u_j = 0\). Axiom 2 (Uniform Marginals): For any index \(j \in \{1, \dots, d\}\), \(C(1, \dots, 1, u_j, 1, \dots, 1) = u_j\). Axiom 3 (\(d\)-Increasing Property): For every hyper-rectangle \(B = \prod_{j=1}^d [a_j, b_j] \subseteq [0, 1]^d\) with \(a_j \le b_j\), the \(C\)-volume of \(B\) is non-negative:

    \[ V_C(B) = \sum_{v \in \text{vertices}(B)} (-1)^{\text{sign}(v)} C(v) \ge 0 \]

    Every copula \(C\) is rigorously constrained by the Fréchet-Hoeffding Bounds:

    \[ W(\mathbf{u}) \le C(\mathbf{u}) \le M(\mathbf{u}) \]

    where the Fréchet-Hoeffding upper bound \(M(\mathbf{u}) = \min(u_1, u_2, \dots, u_d)\) represents perfect positive monotonic dependence (comonotonicity), and the lower bound \(W(\mathbf{u}) = \max\left(1 - d + \sum_{j=1}^d u_j, \, 0\right)\) represents extreme counter-monotonicity (which is a valid copula only for bivariate systems \(d = 2\)).

    Definition 10.4.2 (Sklar's Representation and Inversion Theorem)

    Let \(F\) be an arbitrary joint \(d\)-dimensional cumulative distribution function with continuous marginal distribution functions \(F_1(x_1), F_2(x_2), \dots, F_d(x_d)\) on random vector \(\mathbf{X} = (X_1, \dots, X_d)^\top\) (Sklar, 1959).

    Component 1 (Sklar Representation): There exists a unique copula \(C: [0, 1]^d \to [0, 1]\) such that for all \(\mathbf{x} = (x_1, \dots, x_d)^\top \in \mathbb{R}^d\):

    \[ F(x_1, x_2, \dots, x_d) = C\left( F_1(x_1), \, F_2(x_2), \, \dots, \, F_d(x_d) \right) \]

    Component 2 (Inversion Construction): For any uniform vector \(\mathbf{u} = (u_1, \dots, u_d)^\top \in [0, 1]^d\), the copula is extracted via the generalized inverse (quantile) functions \(F_j^{-1}(u_j) = \inf\{x \in \mathbb{R} : F_j(x) \ge u_j\}\):

    \[ C(u_1, u_2, \dots, u_d) = F\left( F_1^{-1}(u_1), \, F_2^{-1}(u_2), \, \dots, \, F_d^{-1}(u_d) \right) \]

    Component 3 (Probability Density Decomposition): Differentiating the joint CDF yields the joint probability density function \(f(\mathbf{x})\), factored into marginal densities \(f_j(x_j)\) and the copula density \(c(\mathbf{u})\):

    \[ f(x_1, \dots, x_d) = c\left( F_1(x_1), \dots, F_d(x_d) \right) \prod_{j=1}^d f_j(x_j) \]

    where \(c(\mathbf{u}) = \frac{\partial^d C(u_1, \dots, u_d)}{\partial u_1 \dots \partial u_d}\). This decouples marginal fitting from joint dependency estimation.

    Definition 10.4.3 (Archimedean Copula Generator & Tail Dependence Indices)

    An Archimedean Copula is constructed via a continuous, strictly decreasing, convex generator function \(\psi: [0, 1] \to [0, \infty]\) with \(\psi(1) = 0\) and pseudo-inverse \(\psi^{[-1]}(t)\) (Joe, 2014):

    \[ C(u_1, u_2) = \psi^{[-1]}\left( \psi(u_1) + \psi(u_2) \right) \]

    For the Clayton Copula family parameterized by \(\theta \in (0, \infty)\), the generator is \(\psi(t) = \frac{1}{\theta}(t^{-\theta} - 1)\), producing the bivariate distribution function:

    \[ C_\theta(u_1, u_2) = \max\left( u_1^{-\theta} + u_2^{-\theta} - 1, \, 0 \right)^{-1/\theta} \]

    The asymptotic Lower Tail Dependence Index \(\lambda_L\) and Upper Tail Dependence Index \(\lambda_U\) quantify extreme co-movement:

    \[ \lambda_L = \lim_{q \to 0^+} \mathbb{P}\left( U_2 \le q \mid U_1 \le q \right) = \lim_{q \to 0^+} \frac{C(q, q)}{q} = 2^{-1/\theta} > 0 \]
    \[ \lambda_U = \lim_{q \to 1^-} \mathbb{P}\left( U_2 > q \mid U_1 > q \right) = \lim_{q \to 1^-} \frac{1 - 2q + C(q, q)}{1 - q} = 0 \]

    The Clayton copula exhibits strong lower-tail clustering (\(\lambda_L > 0\)) while possessing zero upper-tail dependence (\(\lambda_U = 0\)), making it ideal for asymmetric phenomena like credit default avalanches or biological organ failure.

    Definition 10.4.4 (Frobenius Correlation Error & Higham PSD Matrix Repair)

    Given empirical correlation matrix \(\mathbf{R}_{\text{real}} \in \mathbb{R}^{d \times d}\) and synthetic correlation matrix \(\mathbf{R}_{\text{synth}} \in \mathbb{R}^{d \times d}\), the Frobenius Matrix Error measures overall covariance fidelity:

    \[ \|\mathbf{R}_{\text{real}} - \mathbf{R}_{\text{synth}}\|_F = \sqrt{ \sum_{i=1}^d \sum_{j=1}^d \left( R_{\text{real}, ij} - R_{\text{synth}, ij} \right)^2 } \]

    In production pipelines with pairwise missing entries or mixed correlation estimators, sample correlation matrix \(\hat{\mathbf{R}}\) can become indefinite (possessing eigenvalues \(\lambda_i \le 0\)), causing Cholesky decomposition \(\boldsymbol{\Sigma} = \mathbf{L} \mathbf{L}^\top\) to fail.

    To resolve this, we compute the Nearest Symmetric Positive Semi-Definite Matrix using Higham's spectral projection (Higham, 2002). Given spectral decomposition \(\hat{\mathbf{R}} = \mathbf{V} \boldsymbol{\Lambda} \mathbf{V}^\top\) with \(\boldsymbol{\Lambda} = \text{diag}(\lambda_1, \dots, \lambda_d)\):

    \[ \mathcal{P}_{\mathcal{S}_+}(\hat{\mathbf{R}}) = \mathbf{V} \, \text{diag}\left( \max(\lambda_1, \epsilon), \, \dots, \, \max(\lambda_d, \epsilon) \right) \mathbf{V}^\top \]

    followed by diagonal renormalization \(\mathbf{R}^* = \mathbf{D}^{-1/2} \, \mathcal{P}_{\mathcal{S}_+}(\hat{\mathbf{R}}) \, \mathbf{D}^{-1/2}\) where \(\mathbf{D} = \text{diag}(\mathcal{P}_{\mathcal{S}_+}(\hat{\mathbf{R}}))\), ensuring \(R^*_{jj} = 1.0\) and positive definiteness \(\lambda_{\min}(\mathbf{R}^*) \ge \epsilon > 0\).

    💻 Runnable Executable Python Implementation

    The production Python script below implements the TabularCopulaSynthesizer with Pydantic V2 schemas. It demonstrates Gaussian Copula synthesis via Cholesky decomposition, Higham positive semidefinite matrix projection (Higham, 2002), Clayton Archimedean copula conditional inversion, and Smooth Bootstrap jittering (Efron & Tibshirani, 1994):

    """
Tabular Copula & Correlation Preservation Synthesizer
Implements Gaussian Copula, Bivariate Clayton Copula, and Smooth Bootstrapping.
Validates Frobenius correlation error and positive semi-definite matrix repair.
"""

from typing import Dict, List, Literal, Tuple
import numpy as np
import pandas as pd
from pydantic import BaseModel, Field
from scipy import stats


class CopulaConfig(BaseModel):
    family: Literal["gaussian", "clayton", "smooth_bootstrap"] = "gaussian"
    clayton_theta: float = Field(default=2.5, ge=0.1, le=20.0, description="Clayton copula parameter")
    jitter_bandwidth: float = Field(default=0.05, ge=0.0, le=0.5, description="Smooth bootstrap shrinkage bandwidth")
    random_seed: int = Field(default=42, description="Pseudorandom generator seed")


class CopulaPreservationMetrics(BaseModel):
    family: str
    pearson_r_real: float = Field(description="Empirical Pearson correlation between leading variables")
    pearson_r_synth: float = Field(description="Synthetic Pearson correlation between leading variables")
    spearman_rho_real: float = Field(description="Empirical Spearman rank correlation")
    spearman_rho_synth: float = Field(description="Synthetic Spearman rank correlation")
    frobenius_distance: float = Field(description="Frobenius distance between correlation matrices")
    lower_tail_dependence_empirical: float = Field(description="Empirical lower tail co-movement index P(U2 < q | U1 < q)")
    psd_eigenvalue_repaired: bool = Field(description="Whether Higham spectral repair was triggered")


class TabularCopulaSynthesizer:
    """Production-grade tabular synthesizer preserving multi-variate dependencies and rank orders."""

    def __init__(self, config: CopulaConfig):
        self.config = config
        self.columns: List[str] = []
        self.empirical_marginals: Dict[str, np.ndarray] = {}
        self.latent_corr: np.ndarray = np.array([])
        self.repaired_psd: bool = False

    @staticmethod
    def nearest_positive_semidefinite(matrix: np.ndarray, eps: float = 1e-6) -> Tuple[np.ndarray, bool]:
        """Higham (2002) spectral projection ensuring matrix is symmetric positive semi-definite."""
        sym_matrix = (matrix + matrix.T) / 2.0
        eigvals, eigvecs = np.linalg.eigh(sym_matrix)
        was_repaired = bool(np.any(eigvals < eps))
        eigvals = np.maximum(eigvals, eps)
        repaired = eigvecs @ np.diag(eigvals) @ eigvecs.T

        # Renormalize diagonals to unit variance
        inv_sqrt_diag = 1.0 / np.sqrt(np.diag(repaired))
        repaired = repaired * np.outer(inv_sqrt_diag, inv_sqrt_diag)
        np.fill_diagonal(repaired, 1.0)
        return repaired, was_repaired

    def fit(self, df: pd.DataFrame) -> "TabularCopulaSynthesizer":
        """Fits empirical marginals and estimates latent correlation structure."""
        self.columns = df.select_dtypes(include=[np.number]).columns.tolist()
        d = len(self.columns)
        n = len(df)
        z_matrix = np.zeros((n, d))

        for j, col in enumerate(self.columns):
            vals = df[col].dropna().values
            self.empirical_marginals[col] = np.sort(vals)
            # Continuous empirical probability integral transform (ranks)
            ranks = stats.rankdata(vals) / (n + 1.0)
            z_matrix[:, j] = stats.norm.ppf(ranks)

        raw_corr = np.corrcoef(z_matrix, rowvar=False)
        self.latent_corr, self.repaired_psd = self.nearest_positive_semidefinite(raw_corr)
        return self

    def sample_gaussian(self, n_samples: int, rng: np.random.Generator) -> pd.DataFrame:
        """Draws samples via Cholesky decomposition of the latent correlation matrix."""
        d = len(self.columns)
        l_factor = np.linalg.cholesky(self.latent_corr)
        z_uncorr = rng.standard_normal((n_samples, d))
        z_synth = z_uncorr @ l_factor.T
        u_synth = stats.norm.cdf(z_synth)

        synth_dict = {}
        for j, col in enumerate(self.columns):
            sorted_vals = self.empirical_marginals[col]
            indices = np.clip(u_synth[:, j] * len(sorted_vals), 0, len(sorted_vals) - 1).astype(int)
            synth_dict[col] = sorted_vals[indices]
        return pd.DataFrame(synth_dict)

    def sample_clayton_bivariate(self, n_samples: int, rng: np.random.Generator) -> pd.DataFrame:
        """Samples bivariate Clayton copula via conditional inverse transform."""
        theta = self.config.clayton_theta
        u1 = rng.uniform(0.0001, 0.9999, size=n_samples)
        w = rng.uniform(0.0001, 0.9999, size=n_samples)

        # Conditional inversion: C(u2 | u1) = w -> solve for u2
        u2 = (u1 ** (-theta) * (w ** (-theta / (theta + 1.0)) - 1.0) + 1.0) ** (-1.0 / theta)
        u2 = np.clip(u2, 0.0001, 0.9999)

        col0, col1 = self.columns[0], self.columns[1]
        sorted_0 = self.empirical_marginals[col0]
        sorted_1 = self.empirical_marginals[col1]

        idx0 = np.clip(u1 * len(sorted_0), 0, len(sorted_0) - 1).astype(int)
        idx1 = np.clip(u2 * len(sorted_1), 0, len(sorted_1) - 1).astype(int)
        return pd.DataFrame({col0: sorted_0[idx0], col1: sorted_1[idx1]})

    def sample_smooth_bootstrap(
        self, df_real: pd.DataFrame, n_samples: int, rng: np.random.Generator
    ) -> pd.DataFrame:
        """Draws non-parametric bootstrap resamples with moment-preserving Gaussian jitter."""
        n = len(df_real)
        idx = rng.choice(n, size=n_samples, replace=True)
        resampled = df_real.iloc[idx][self.columns].copy().values
        cov_matrix = df_real[self.columns].cov().values

        lam = self.config.jitter_bandwidth
        noise = rng.multivariate_normal(
            mean=np.zeros(len(self.columns)), cov=(lam ** 2) * cov_matrix, size=n_samples
        )
        smoothed = resampled + np.sqrt(max(0.0, 1.0 - lam ** 2)) * noise
        return pd.DataFrame(smoothed, columns=self.columns)

    def sample(self, df_real: pd.DataFrame, n_samples: int) -> pd.DataFrame:
        """Dispatches sampling according to configured copula family."""
        rng = np.random.default_rng(self.config.random_seed)
        if self.config.family == "clayton" and len(self.columns) >= 2:
            return self.sample_clayton_bivariate(n_samples, rng)
        elif self.config.family == "smooth_bootstrap":
            return self.sample_smooth_bootstrap(df_real, n_samples, rng)
        else:
            return self.sample_gaussian(n_samples, rng)

    def evaluate_preservation(
        self, df_real: pd.DataFrame, df_synth: pd.DataFrame
    ) -> CopulaPreservationMetrics:
        """Computes bivariate and matrix-level correlation preservation metrics."""
        c1, c2 = self.columns[0], self.columns[1]
        r_real = float(df_real[c1].corr(df_real[c2]))
        r_synth = float(df_synth[c1].corr(df_synth[c2]))

        rho_real, _ = stats.spearmanr(df_real[c1], df_real[c2])
        rho_synth, _ = stats.spearmanr(df_synth[c1], df_synth[c2])

        corr_real = df_real[self.columns].corr().values
        corr_synth = df_synth[self.columns].corr().values
        frob = float(np.linalg.norm(corr_real - corr_synth, ord="fro"))

        # Lower tail dependence empirical proxy: P(U2 <= q | U1 <= q) for q = 0.10
        q = 0.10
        q1 = np.quantile(df_real[c1], q)
        q2 = np.quantile(df_real[c2], q)
        lower_joint = np.mean((df_synth[c1] <= q1) & (df_synth[c2] <= q2))
        lower_cond = float(lower_joint / q)

        return CopulaPreservationMetrics(
            family=self.config.family,
            pearson_r_real=r_real,
            pearson_r_synth=r_synth,
            spearman_rho_real=float(rho_real),
            spearman_rho_synth=float(rho_synth),
            frobenius_distance=frob,
            lower_tail_dependence_empirical=lower_cond,
            psd_eigenvalue_repaired=self.repaired_psd,
        )

    Self-Assessment 10.4.1: Kendall's Tau Derivation for the Archimedean Clayton Copula

    Given an Archimedean Clayton Copula with generator \(\psi(t) = \frac{1}{\theta}(t^{-\theta} - 1)\) for parameter \(\theta > 0\), show that Kendall's rank correlation coefficient \(\tau\) is given by:

    \[\tau = \frac{\theta}{\theta + 2}\]

    and determine the required parameter \(\theta\) to synthesize bivariate asset returns exhibiting a rank correlation of \(\tau = 0.60\).

    Reveal Detailed Solution

    Mathematical Derivation:

    For any Archimedean copula generated by \(\psi(t)\), Genest & MacKay established that Kendall's tau satisfies the integral:

    \[\tau = 1 + 4 \int_0^1 \frac{\psi(t)}{\psi'(t)} dt\]

    For the Clayton copula generator:

    Step 1 (Compute Derivative): \(\psi'(t) = \frac{d}{dt}\left[ \frac{1}{\theta}(t^{-\theta} - 1) \right] = -t^{-\theta - 1}\).

    Step 2 (Evaluate Quotient):

    \[\frac{\psi(t)}{\psi'(t)} = \frac{\frac{1}{\theta}(t^{-\theta} - 1)}{-t^{-\theta - 1}} = -\frac{1}{\theta} \left( t - t^{\theta + 1} \right) = \frac{t^{\theta + 1} - t}{\theta}\]

    Step 3 (Integrate Over Unit Interval):

    \[\int_0^1 \left( \frac{t^{\theta+1} - t}{\theta} \right) dt = \frac{1}{\theta} \left[ \frac{t^{\theta + 2}}{\theta + 2} - \frac{t^2}{2} \right]_0^1 = -\frac{1}{2(\theta + 2)}\]

    Step 4 (Substitute into Kendall's Equation):

    \[\tau = 1 + 4 \left( -\frac{1}{2(\theta + 2)} \right) = 1 - \frac{2}{\theta + 2} = \frac{\theta}{\theta + 2}\]

    To calibrate for \(\tau = 0.60\):

    \[\theta = \frac{2\tau}{1 - \tau} = \frac{2(0.60)}{1 - 0.60} = \frac{1.20}{0.40} = 3.0\]

    Setting \(\theta = 3.0\) guarantees an exact Kendall rank correlation of \(0.60\) and an asymptotic lower-tail dependence of \(\lambda_L = 2^{-1/3} \approx 0.7937\).

    Self-Assessment 10.4.2: Cholesky Breakdown & Higham Nearest Positive Semi-Definite Matrix

    Suppose pairwise data collection yields an empirical correlation matrix with eigenvalues \(\boldsymbol{\Lambda} = \{1.85, 0.40, -0.25\}\).

    1. Explain why direct Cholesky decomposition \(\boldsymbol{\Sigma} = \mathbf{L} \mathbf{L}^\top\) fails.
    2. Demonstrate how Higham's spectral projection repairs this matrix to allow correlated random vector synthesis.
    Reveal Detailed Solution

    Step-by-Step Explanation:

    1. Failure of Cholesky Factorization: Cholesky decomposition requires that the matrix \(\boldsymbol{\Sigma}\) be strictly positive definite (\(\mathbf{x}^\top \boldsymbol{\Sigma} \mathbf{x} > 0\) for all \(\mathbf{x} \ne \mathbf{0}\)). A symmetric matrix is positive definite if and only if all its eigenvalues are strictly positive (\(\lambda_i > 0\)). Here, \(\lambda_3 = -0.25 < 0\). Attempting Cholesky factorization results in calculating the square root of a negative pivot:

    \[l_{33} = \sqrt{\Sigma_{33} - \sum_{k=1}^2 l_{3k}^2} \in \mathbb{C} \quad (\text{imaginary number})\]

    causing linear algebra routines to throw a LinAlgError: Matrix is not positive definite.

    2. Higham Spectral Projection Repair: Higham's algorithm decomposes the symmetric matrix \(\mathbf{A} = \mathbf{V} \boldsymbol{\Lambda} \mathbf{V}^\top\) and projects it onto the positive semidefinite cone \(\mathcal{S}_+^d\):

    Step 1 (Eigenvalue Clipping): Negative eigenvalues are clipped to a positive tolerance \(\epsilon = 10^{-6}\):

    \[\boldsymbol{\Lambda}_+ = \text{diag}(1.85, \, 0.40, \, 10^{-6})\]

    Step 2 (Matrix Reconstruction): The repaired matrix is reconstructed via \(\mathbf{A}_{\text{psd}} = \mathbf{V} \boldsymbol{\Lambda}_+ \mathbf{V}^\top\).

    Step 3 (Diagonal Renormalization): Diagonals are rescaled to 1.0 to preserve unit-diagonal correlation properties:

    \[\mathbf{R}^* = \mathbf{D}^{-1/2} \mathbf{A}_{\text{psd}} \mathbf{D}^{-1/2}, \quad \text{where } \mathbf{D} = \text{diag}(\mathbf{A}_{\text{psd}})\]

    Since all eigenvalues of \(\mathbf{R}^*\) are now strictly positive (\(\lambda_{\min} \ge 10^{-6}\)), the Cholesky factor \(\mathbf{L} = \text{chol}(\mathbf{R}^*)\) is guaranteed to exist with real entries, allowing correlated Gaussian draws \(\mathbf{z} = \mathbf{L} \boldsymbol{\xi}\).

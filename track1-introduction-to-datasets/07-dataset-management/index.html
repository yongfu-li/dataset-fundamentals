    1. The Imperative of Dataset Governance

    In production machine learning and scientific discovery, the longevity and credibility of research depend on the infrastructure supporting the data: who can access it, which exact version was used to train a model, where disaster recovery backups reside, and how privacy regulations are enforced [Voigt2017].

    A dataset is not an immutable static file; it evolves through a multi-stage Data Lifecycle:

    flowchart TD
    Ingest["1. Ingestion & Raw Staging<br/>(Bronze: Immutable Capture)"] --> Clean["2. Cleaning & Standardization<br/>(Silver: Schema Validation)"]
    Clean --> Curate["3. Curated Feature Tables<br/>(Gold: DVC Lineage & Versioning)"]
    Curate --> Serve["4. Model Training & Serving<br/>(RBAC Access & Audit Logging)"]
    Serve --> Archive["5. Archival & Retention<br/>(Cold Storage: S3 Glacier)"]
    Archive --> Purge["6. Cryptographic Erasure<br/>(GDPR Art. 17 Tombstoning)"]

    Without systematic governance, pipelines succumb to Data Debt [Sculley2015]: silent upstream modifications overwrite training sets, undocumented preprocessing steps make results irreproducible, and unmonitored personal data incurs severe legal penalties under international privacy statutes.

    2. The Six Pillars of Mature Dataset Management

    Mature data engineering organizations build their infrastructure upon six foundational pillars:

    Management Pillar Core Objective Key Architectural Pattern Tooling Ecosystem
    1. Data Version Control Immutable content-addressable version tracking linking specific code commits to exact dataset states. Hash pointers (\(\text{SHA-256}\)) stored in Git sidecars; raw binaries stored in object storage. DVC, LakeFS, Git LFS
    2. Pipeline Reproducibility Declarative Directed Acyclic Graph (DAG) execution ensuring transformations are deterministic. Pipeline manifests with explicit input/output file hashes and cache invalidation. DVC Pipelines, Apache Airflow, Prefect
    3. Metadata & Lineage Tracking every transformation applied to an attribute from ingestion to downstream features. OpenLineage specification, automated runtime graph capture. Marquez, Amundsen, DataHub
    4. Resilient Storage & DR Preventing unrecoverable loss caused by operator error or physical hardware degradation. The 3-2-1 backup strategy (3 copies, 2 media types, 1 offsite geographic replica). AWS S3 Cross-Region Replication, ZFS
    5. Fine-Grained Access (RBAC) Ensuring users access only the minimum necessary attributes required for their specific role. Role-Based Access Control, Dynamic Column Masking, Row-Level Filtering. Apache Ranger, AWS Lake Formation
    6. Cataloging & Discovery Preventing duplicated engineering work by making existing datasets discoverable. Centralized searchable schema catalogs with FAIR metadata tags. CKAN, AWS Glue Catalog

    3.1 The Right to Erasure (GDPR Article 17)

    Under GDPR, data subjects have the right to demand the deletion of their personal data without undue delay. In immutable, append-only columnar storage (e.g., Parquet in S3), deleting a single user's record requires rewriting an entire \(512\text{ MB}\) file.

    To solve this, modern data architectures deploy Cryptographic Erasure (Crypto-Tombstoning): each individual subject's records are encrypted with a unique per-user key \(K_u\). When an erasure request arrives:

    \[\text{Erase}(u) \implies \text{DestroyKey}(K_u)\]

    The physical ciphertext remains in the immutable archive, but becomes provably unrecoverable random noise, satisfying legal erasure mandates without rewriting gigabytes of columnar data [Voigt2017].

    5. Production Engineering Implementation

    The following production script implements an automated Content-Addressable Dataset Lineage Hasher and Differential Privacy Noise Injector:

    """
Dataset Governance, Lineage Hashing & Anonymization Engine
Demonstrating SHA-256 content addressability, DVC manifest generation,
and Laplace Differential Privacy for continuous feature queries.
"""

from __future__ import annotations
import hashlib
import json
import os
from pathlib import Path
import numpy as np
import polars as pl


def compute_dataset_hash(file_path: str) -> str:
    """Computes deterministic SHA-256 hash of dataset bytes."""
    sha256 = hashlib.sha256()
    with open(file_path, "rb") as f:
        while chunk := f.read(65536):
            sha256.update(chunk)
    return sha256.hexdigest()


def generate_dvc_sidecar(data_file: str, dvc_file: str) -> None:
    """Creates a DVC-compatible metadata pointer sidecar."""
    file_stat = os.stat(data_file)
    content_hash = compute_dataset_hash(data_file)

    manifest = {
        "schema_version": "2.0",
        "outs": [
            {
                "path": os.path.basename(data_file),
                "sha256": content_hash,
                "size_bytes": file_stat.st_size,
                "created_by": "Dataset Engineering Governance Engine",
            }
        ]
    }

    with open(dvc_file, "w") as f:
        json.dump(manifest, f, indent=2)
    print(f"Generated DVC lineage sidecar: {dvc_file} (Hash: {content_hash[:12]}...)")


def apply_differential_privacy_laplace(true_mean: float, epsilon: float, sensitivity: float) -> float:
    """
    Adds calibrated Laplace noise to satisfy ε-Differential Privacy:
    Noise ~ Laplace(0, Sensitivity / ε)
    """
    scale = sensitivity / epsilon
    noise = np.random.laplace(0, scale)
    return float(true_mean + noise)


if __name__ == "__main__":
    # Create sample dataset
    sample_df = pl.DataFrame({
        "customer_id": [101, 102, 103, 104, 105],
        "spend_usd": [150.0, 320.0, 45.0, 890.0, 120.0],
    })
    temp_csv = "curated_customers.csv"
    temp_dvc = "curated_customers.csv.dvc"
    sample_df.write_csv(temp_csv)

    # 1. Generate Lineage Sidecar
    generate_dvc_sidecar(temp_csv, temp_dvc)

    # 2. Query with Differential Privacy (protecting individual spend)
    raw_mean = float(sample_df["spend_usd"].mean())
    dp_mean = apply_differential_privacy_laplace(true_mean=raw_mean, epsilon=0.5, sensitivity=100.0)

    print(f"\nExact Empirical Mean Spend: ${raw_mean:.2f}")
    print(f"ε-Differentially Private Mean (ε=0.5): ${dp_mean:.2f}")

    # Clean up temporary artifacts
    if os.path.exists(temp_csv): os.remove(temp_csv)
    if os.path.exists(temp_dvc): os.remove(temp_dvc)

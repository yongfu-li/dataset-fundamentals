    🎯 Conceptual Overview & Derivation

    Even when research laboratories publish identical source code repositories and provide access to identical raw data files, computational experiments frequently produce non-identical model weights, divergent evaluation metrics, and irreproducible training curves (Henderson et al., 2018; Makonin, 2024; Stodden et al., 2016). This systemic reproducibility breakdown originates from four primary vulnerability vectors:

    1. Hardware & Micro-Architectural Non-Determinism: Multi-threaded floating-point reductions on GPUs where asynchronous thread warp scheduling alters accumulation order (Higham, 2002), combined with architectural differences in Tensor Core accumulations (e.g., NVIDIA A100 vs H100).
    2. Silent Environmental & Dependency Drift: Hidden mutations in underlying linear algebra routines (cuDNN, MKL, OpenBLAS) and operating system dynamic libraries (Boettiger, 2015; Pineau et al., 2021).
    3. Data Leakage & Benchmark Contamination: Unintentional inclusion of evaluation records or verbatim \(n\)-grams within massive web-crawled pre-training datasets, creating an illusion of reasoning generalization.
    4. Covariate & Temporal Distribution Shift: Systematic divergence between the training probability distribution and external test cohorts, causing unmonitored generalization collapse (Sculley et al., 2015; Wilkinson et al., 2016).

    The Hidden Technical Debt of Unstandardized Data

    Machine learning engineering exhibits severe structural debt when data pipelines lack rigorous standardization. As established by Sculley et al. (2015), data dependencies in real-world AI systems create far more maintenance fragility than traditional software code:

    • Data Cascades: Upstream data quality defects compound through downstream feature extractors, embeddings, and surrogate models, triggering non-linear catastrophic failures.
    • Feedback Loops: Models deployed in the wild influence user behavior, contaminating future training datasets with their own algorithmic predictions.
    • Under-Documented Pipelines: Ad-hoc Python preprocessing scripts containing unversioned heuristics prevent third-party auditability.

    To mitigate this technical debt, the scientific community has converged on formal reporting standards (such as the NeurIPS Reproducibility Checklist formulated by Pineau et al. (2021)), containerized execution environments (Boettiger, 2015), and standardized machine-actionable metadata standards (Wilkinson et al., 2016).

    Mathematical Formulations of Challenges & Standards

    Definition 13.2.1: Dataset Lineage Provenance DAG & Blast Radius

    Let an enterprise computational workflow be modeled as a bipartite Directed Acyclic Graph (DAG):

    \[\mathcal{G} = \left( \mathcal{V}, \mathcal{E} \right), \quad \mathcal{V} = \mathcal{V}_{\mathcal{D}} \cup \mathcal{V}_{\mathcal{T}}\]

    where: - \(\mathcal{V}_{\mathcal{D}} = \{\mathcal{D}_1, \mathcal{D}_2, \dots, \mathcal{D}_M\}\) represents immutable dataset artifacts, each addressed by cryptographic digest \(\mathcal{H}(\mathcal{D}_i) \in \{0, 1\}^{256}\). - \(\mathcal{V}_{\mathcal{T}} = \{\tau_1, \tau_2, \dots, \tau_K\}\) represents deterministic transformation operators (tokenization, normalization, featurization, training). - \(\mathcal{E} \subseteq (\mathcal{V}_{\mathcal{D}} \times \mathcal{V}_{\mathcal{T}}) \cup (\mathcal{V}_{\mathcal{T}} \times \mathcal{V}_{\mathcal{D}})\) represents directed causal dataflow edges.

    Upstream Provenance Ancestry (Reachability Cone)

    For any target dataset or model artifact \(\mathcal{D}_{\text{target}} \in \mathcal{V}_{\mathcal{D}}\), its complete backward provenance cone \(\mathcal{R}^-(\mathcal{D}_{\text{target}})\) is the set of all ancestor vertices:

    \[\mathcal{R}^-\left(\mathcal{D}_{\text{target}}\right) = \left\{ u \in \mathcal{V} \;\middle|\; u \rightsquigarrow \mathcal{D}_{\text{target}} \right\}\]

    where \(u \rightsquigarrow v\) denotes the existence of a directed path from \(u\) to \(v\).

    Downstream Contamination Blast Radius

    When an upstream record defect, unversioned script mutation, or data labeling corruption occurs at transformation operator \(\tau_j\), its forward impact is quantified by its Blast Radius \(\mathcal{B}(\tau_j)\):

    \[\mathcal{B}(\tau_j) = \left| \mathcal{R}^+(\tau_j) \right| = \left| \left\{ v \in \mathcal{V} \;\middle|\; \tau_j \rightsquigarrow v \right\} \right|\]

    Using the DAG adjacency matrix \(A \in \{0, 1\}^{|\mathcal{V}| \times |\mathcal{V}|}\), the reachability matrix \(R\) is computed via the matrix resolvent:

    \[R = \sum_{k=1}^{|\mathcal{V}|-1} A^k = (I - A)^{-1} - I\]
    Causal Error Propagation Bound

    If an upstream dataset \(v \in \mathcal{R}^-(\mathcal{M})\) experiences feature perturbation \(\Delta v\), and each downstream operator \(\tau_k\) has local Lipschitz constant \(L_k\), the resulting drift in downstream model inference error \(\Delta \epsilon_{\text{model}}\) is bounded by:

    \[\Delta \epsilon_{\text{model}} \le \sum_{v \in \mathcal{R}^-(\mathcal{M})} \left( \prod_{e \in \text{path}(v, \mathcal{M})} L_e \right) \|\Delta v\|\]

    Definition 13.2.2: Distribution Shift Divergence & Wasserstein Bounds

    In empirical benchmark replication, a model trained on source distribution \(P(X, Y)\) is evaluated on target distribution \(Q(X, Y)\). Under covariate shift, the input marginal distributions differ (\(P(X) \ne Q(X)\)), while the conditional concept mapping remains invariant (\(P(Y \mid X) = Q(Y \mid X)\)).

    The Wasserstein-1 Distance (Earth Mover's Distance)

    The geometric discrepancy between empirical training features \(X \sim P\) and test features \(X' \sim Q\) is formalized by the Wasserstein-1 metric:

    \[\mathcal{W}_1(P, Q) = \inf_{\gamma \in \Pi(P, Q)} \mathbb{E}_{(x, x') \sim \gamma}\left[ \|x - x'\| \right]\]

    where \(\Pi(P, Q)\) denotes the collection of all joint probability distributions (couplings) whose marginals are \(P\) and \(Q\). By Kantorovich-Rubinstein duality:

    \[\mathcal{W}_1(P, Q) = \sup_{\|f\|_L \le 1} \left| \mathbb{E}_{X \sim P}[f(X)] - \mathbb{E}_{X' \sim Q}[f(X')] \right|\]

    For one-dimensional continuous features, \(\mathcal{W}_1\) evaluates directly as the \(L_1\) area between cumulative distribution functions (CDFs):

    \[\mathcal{W}_1(P, Q) = \int_{-\infty}^{\infty} \left| F_P(t) - F_Q(t) \right| dt\]
    Kolmogorov-Smirnov Test Statistic

    The maximum vertical deviation between empirical CDFs provides the non-parametric Kolmogorov-Smirnov (KS) statistic:

    \[D_{\text{KS}} = \sup_{t \in \mathbb{R}} \left| \hat{F}_P(t) - \hat{F}_Q(t) \right|\]

    A distribution shift alert is triggered at significance level \(\alpha = 0.05\) if \(D_{\text{KS}} > c(\alpha) \sqrt{\frac{n_P + n_Q}{n_P n_Q}}\), where \(c(0.05) \approx 1.358\).

    Generalization Error Upper Bound Under Covariate Shift

    For a predictive model \(h: \mathcal{X} \to \mathcal{Y}\) with \(L_h\)-Lipschitz loss function \(\ell\), the expected evaluation risk on unseen target domain \(Q\) is bounded by:

    \[\epsilon_Q(h) \le \epsilon_P(h) + 2 L_h \mathcal{W}_1(P, Q) + \Delta_{\text{disc}}\]

    where \(\Delta_{\text{disc}} = \inf_{h^*} \left( \epsilon_P(h^*) + \epsilon_Q(h^*) \right)\) represents domain discrepancy. When \(\mathcal{W}_1(P, Q) > \epsilon_{\text{threshold}}\), evaluation accuracy collapses predictably.

    Definition 13.2.3: Data Leakage Mutual Information & Benchmark Contamination

    Data leakage occurs when evaluation information contaminates the model training process, yielding artificially inflated benchmark performance that evaporates on external deployment.

    Information-Theoretic Data Leakage

    Let \(\mathcal{D}_{\text{train}}\) and \(\mathcal{D}_{\text{test}}\) represent training and testing partitions. Complete statistical partitioning independence implies zero mutual information:

    \[I\left( \mathcal{D}_{\text{train}} ; \mathcal{D}_{\text{test}} \right) = H\left(\mathcal{D}_{\text{test}}\right) - H\left(\mathcal{D}_{\text{test}} \mid \mathcal{D}_{\text{train}}\right) = 0\]

    If duplicate records, near-duplicate documents, or patient cohort overlaps exist, \(I(\mathcal{D}_{\text{train}}; \mathcal{D}_{\text{test}}) > 0\), creating severe inductive bias.

    Observed Accuracy Inflation Under Contamination

    Let \(\eta \in [0, 1]\) denote the fraction of contaminated records in the evaluation benchmark:

    \[\eta = \frac{\left| \mathcal{D}_{\text{test}} \cap \mathcal{D}_{\text{train}} \right|}{\left| \mathcal{D}_{\text{test}} \right|}\]

    The observed benchmark accuracy \(\text{Acc}_{\text{obs}}\) is a convex combination of true generalizable performance \(\text{Acc}_{\text{true}}\) and verbatim memorized performance \(\text{Acc}_{\text{mem}}\):

    \[\mathbb{E}\left[ \text{Acc}_{\text{obs}} \right] = (1 - \eta) \text{Acc}_{\text{true}} + \eta \cdot \text{Acc}_{\text{mem}}\]
    Exact Mathematical De-biasing Invariant

    To recover the uncorrupted scientific effect size from a contaminated evaluation run:

    \[\text{Acc}_{\text{true}} = \frac{\text{Acc}_{\text{obs}} - \eta \cdot \text{Acc}_{\text{mem}}}{1 - \eta}\]

    For example, if an LLM achieves an observed score \(\text{Acc}_{\text{obs}} = 88.0\%\) on a code generation benchmark, but post-hoc audit uncovers \(\eta = 20\%\) verbatim training overlap where \(\text{Acc}_{\text{mem}} = 100\%\), the true generalizable performance is:

    \[\text{Acc}_{\text{true}} = \frac{0.88 - (0.20 \times 1.00)}{1 - 0.20} = \frac{0.68}{0.80} = 85.0\%\]
    MinHash LSH Decontamination Error Bound

    To detect document contamination across web-scale corpora (\(N > 10^9\) documents), pipelines deploy MinHash Locality-Sensitive Hashing (LSH) with \(k\) independent hash permutations. The probability that MinHash signatures match equals the Jaccard similarity \(J(A, B) = \frac{|A \cap B|}{|A \cup B|}\):

    \[\Pr\left[ h_{\pi}(A) = h_{\pi}(B) \right] = J(A, B)\]

    By Chernoff concentration bounds, the empirical MinHash estimator \(\hat{J} = \frac{1}{k} \sum_{i=1}^k \mathbb{I}(h_i(A) = h_i(B))\) satisfies:

    \[\Pr\left[ |\hat{J} - J| \ge \epsilon \right] \le 2\exp\left( -2 k \epsilon^2 \right)\]

    With \(k = 128\) hash functions and error tolerance \(\epsilon = 0.05\), the probability of false matching is bounded below \(2\exp(-2 \times 128 \times 0.0025) \approx 0.105\).

    Definition 13.2.4: Open Science Compliance Index & Metadata Schema Invariants

    To operationalize reproducibility governance across academic and industrial research, the NeurIPS Reproducibility Checklist (Pineau et al., 2021) and modern metadata specifications (W3C DCAT, ML CROISSANT, Schema.org) define verifiable compliance scoring.

    Reproducibility Compliance Index

    The composite checklist index \(\mathcal{I}_{\text{rep}} \in [0, 1]\) evaluates \(K\) mandatory reporting standards:

    \[\mathcal{I}_{\text{rep}} = \frac{\sum_{k=1}^K w_k \cdot \mathbb{I}\left( \text{Criterion}_k = \text{Satisfied} \right)}{\sum_{k=1}^K w_k}\]

    Key weighted criteria include: 1. \(w_1 = 0.25\): Cryptographic SHA-256 dataset partition checksums. 2. \(w_2 = 0.20\): Explicit random seeds and deterministic hardware execution flags. 3. \(w_3 = 0.20\): Fully pinned container image digest and lockfiles (poetry.lock). 4. \(w_4 = 0.20\): Hyperparameter tuning bounds and search budgets. 5. \(w_5 = 0.15\): Open data licensing and persistent DOI accession.

    Metadata Information Entropy & Minimum Description Length

    Let \(\mathcal{M} = (m_1, m_2, \dots, m_M)\) denote the serialized JSON-LD metadata fields describing an experiment. The Shannon entropy of missing metadata attributes measures epistemic ambiguity:

    \[H(\mathcal{M}) = -\sum_{i=1}^M p(m_i) \log_2 p(m_i)\]

    A computational workflow achieves unconditional reproduciblity if and only if the conditional environment entropy collapses to zero:

    \[H\left( \mathcal{E} \;\middle|\; \mathcal{M} \right) = 0\]

    guaranteeing that any third-party computing platform can reconstruct bitwise-identical runtime states without guesswork.

Dataset Standards, Distribution Shift, and Decontamination Auditing Engine
Production-grade Pydantic V2 implementation for open science compliance,
1D Wasserstein-1 drift calculation, data leakage de-biasing, and DAG blast radius.
"""

import bisect

from typing import Dict, List, Optional, Set, Tuple

class DatasetMetadataSchema(BaseModel):
    """Validates open science dataset metadata against CROISSANT / W3C DCAT standards."""
    name: str = Field(..., description="Unique dataset identifier")
    version: str = Field(..., pattern=r"^\d+\.\d+\.\d+$", description="Semantic versioning string")
    sha256: str = Field(..., description="Cryptographic SHA-256 digest")
    license: str = Field(..., description="Open data license identifier (e.g. CC-BY-4.0, CC0-1.0)")
    author_orcid: str = Field(..., pattern=r"^\d{4}-\d{4}-\d{4}-\d{3}[\dX]$", description="Author ORCID identifier")
    fair_score: float = Field(..., ge=0.0, le=1.0, description="Composite FAIR compliance index")

    @field_validator("sha256")
    @classmethod
    def validate_sha256_format(cls, v: str) -> str:
        if len(v) != 64 or not all(c in "0123456789abcdefABCDEF" for c in v):
            raise ValueError("SHA-256 digest must be exactly 64 hexadecimal characters.")
        return v.lower()


class DistributionShiftAlert(BaseModel):
    """Encapsulates continuous feature distribution shift metrics."""
    feature_name: str
    wasserstein_distance: float
    ks_statistic: float
    shift_detected: bool
    generalization_error_upper_bound: float


class DataLeakageReport(BaseModel):
    """Quantifies benchmark contamination and debiased accuracy."""
    train_records: int
    test_records: int
    leakage_records: int
    contamination_fraction: float
    observed_inflated_accuracy: float
    estimated_true_accuracy: float


class DatasetStandardsAuditingEngine:
    """Production engine for dataset standards, drift detection, and contamination auditing."""

    @staticmethod
    def compute_1d_wasserstein(sample_p: List[float], sample_q: List[float]) -> float:
        """
        Computes exact 1D Wasserstein-1 (Earth Mover's Distance) between two empirical samples:
        W_1(P, Q) = integral |F_P(t) - F_Q(t)| dt.
        Complexity: O(N log N) via sorted empirical CDF integration.
        """
        sp = sorted(sample_p)
        sq = sorted(sample_q)
        all_vals = sorted(list(set(sp + sq)))
        if not all_vals:
            return 0.0

        def empirical_cdf(val: float, sample: List[float]) -> float:
            return bisect.bisect_right(sample, val) / len(sample)

        w1_distance = 0.0
        for i in range(len(all_vals) - 1):
            x_curr = all_vals[i]
            x_next = all_vals[i + 1]
            dx = x_next - x_curr
            cdf_p = empirical_cdf(x_curr, sp)
            cdf_q = empirical_cdf(x_curr, sq)
            w1_distance += abs(cdf_p - cdf_q) * dx

        return w1_distance

    @classmethod
    def audit_distribution_shift(
        cls,
        feature_name: str,
        train_vals: List[float],
        eval_vals: List[float],
        base_train_loss: float = 0.05,
        lipschitz_constant: float = 1.0,
        threshold_w1: float = 0.15
    ) -> DistributionShiftAlert:
        """
        Detects distribution shift via Wasserstein-1 and Kolmogorov-Smirnov statistics,
        bounding target domain generalization error.
        """
        w1 = cls.compute_1d_wasserstein(train_vals, eval_vals)

        # Non-parametric Kolmogorov-Smirnov calculation
        st = sorted(train_vals)
        se = sorted(eval_vals)
        all_vals = sorted(list(set(st + se)))
        max_ks = 0.0
        for v in all_vals:
            cdft = bisect.bisect_right(st, v) / len(st)
            cdfe = bisect.bisect_right(se, v) / len(se)
            max_ks = max(max_ks, abs(cdft - cdfe))

        shift_flag = w1 > threshold_w1
        gen_bound = base_train_loss + 2.0 * lipschitz_constant * w1

        return DistributionShiftAlert(
            feature_name=feature_name,
            wasserstein_distance=w1,
            ks_statistic=max_ks,
            shift_detected=shift_flag,
            generalization_error_upper_bound=gen_bound
        )

    @staticmethod
    def audit_data_leakage(
        train_hashes: Set[str],
        test_hashes: Set[str],
        observed_test_acc: float = 0.92,
        memorized_acc: float = 0.99
    ) -> DataLeakageReport:
        """
        Audits train-test split leakage and computes de-biased true generalization performance:
        Acc_true = (Acc_obs - eta * Acc_mem) / (1 - eta).
        """
        leakage_set = train_hashes.intersection(test_hashes)
        n_leak = len(leakage_set)
        n_test = len(test_hashes)
        eta = n_leak / max(1, n_test)

        if eta < 1.0:
            true_acc = (observed_test_acc - eta * memorized_acc) / (1.0 - eta)
            true_acc = max(0.0, min(1.0, true_acc))
        else:
            true_acc = 0.0

        return DataLeakageReport(
            train_records=len(train_hashes),
            test_records=n_test,
            leakage_records=n_leak,
            contamination_fraction=eta,
            observed_inflated_accuracy=observed_test_acc,
            estimated_true_accuracy=true_acc
        )

    @staticmethod
    def compute_blast_radius(adj_matrix: List[List[int]], source_node: int) -> int:
        """
        Computes downstream reachable nodes (blast radius) in an execution DAG
        using Breadth-First Search (BFS).
        """
        n = len(adj_matrix)
        visited: Set[int] = set()
        queue = [source_node]
        while queue:
            curr = queue.pop(0)
            for neighbor in range(n):
                if adj_matrix[curr][neighbor] == 1 and neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        return len(visited)

    @staticmethod
    def evaluate_neurips_checklist(criteria_dict: Dict[str, bool]) -> float:
        """Evaluates weighted NeurIPS reproducibility checklist compliance score."""
        weights = {
            "fixed_seeds": 0.20,
            "data_hashes": 0.25,
            "deterministic_cuda": 0.20,
            "environment_lockfile": 0.20,
            "hyperparameter_bounds": 0.15
        }
        total_w = sum(weights.values())
        score = sum(weights[k] * float(criteria_dict.get(k, False)) for k in weights)
        return score / total_w

    Self-Assessment 1: Benchmark Contamination De-biasing & MinHash Sample Size

    An open-source language model reports an observed Top-1 accuracy of \(\text{Acc}_{\text{obs}} = 86.0\%\) on a reasoning benchmark of \(n_{\text{test}} = 1{,}000\) questions. A subsequent MinHash audit reveals that \(\eta = 25\%\) (\(250\) questions) were present verbatim in the pre-training web crawl, where the model achieves memorized accuracy \(\text{Acc}_{\text{mem}} = 100\%\).

    1. Calculate the true, uncorrupted generalization accuracy \(\text{Acc}_{\text{true}}\).
    2. What is the minimum number of MinHash hash permutations \(k\) required to guarantee that the estimated Jaccard overlap \(\hat{J}\) is within \(\epsilon = 0.04\) of true similarity \(J\) with confidence \(95\%\) (\(\delta_{\text{conf}} = 0.05\))?
    Reveal Detailed Solution

    Step-by-Step Derivation:

    1. Calculate True De-biased Accuracy: Under the mixture model of benchmark contamination:

    \[ \text{Acc}_{\text{obs}} = (1 - \eta) \text{Acc}_{\text{true}} + \eta \cdot \text{Acc}_{\text{mem}} \]

    Solving for \(\text{Acc}_{\text{true}}\):

    \[ \text{Acc}_{\text{true}} = \frac{\text{Acc}_{\text{obs}} - \eta \cdot \text{Acc}_{\text{mem}}}{1 - \eta} = \frac{0.86 - (0.25 \times 1.00)}{1 - 0.25} = \frac{0.86 - 0.25}{0.75} = \frac{0.61}{0.75} \approx 81.33\% \]

    The model's true generalizable accuracy is 81.33%, revealing that benchmark contamination inflated reported performance by nearly \(5\) percentage points!

    2. Calculate Required MinHash Hash Functions \(k\): By the Chernoff concentration bound for MinHash estimators:

    \[ \Pr\left[ |\hat{J} - J| \ge \epsilon \right] \le 2\exp\left( -2 k \epsilon^2 \right) \le \delta_{\text{conf}} \]

    Taking the natural logarithm:

    \[ \ln\left( \frac{2}{\delta_{\text{conf}}} \right) \le 2 k \epsilon^2 \implies k \ge \frac{\ln(2 / \delta_{\text{conf}})}{2 \epsilon^2} \]

    For \(\delta_{\text{conf}} = 0.05\) and \(\epsilon = 0.04\):

    \[ \ln\left( \frac{2}{0.05} \right) = \ln(40) \approx 3.68888 \]
    \[ 2 \epsilon^2 = 2 \times (0.04)^2 = 2 \times 0.0016 = 0.0032 \]
    \[ k \ge \frac{3.68888}{0.0032} \approx 1{,}152.78 \implies k = 1{,}153 \text{ hash functions} \]

    A minimum of 1,153 independent hash permutations is required to bound decontamination estimation error within \(\pm 0.04\) at \(95\%\) confidence.

    Self-Assessment 2: Covariate Shift and Generalization Error Upper Bounds

    A clinical diagnostic model has training loss \(\epsilon_P(h) = 0.06\) on historical hospital records. The loss function has Lipschitz constant \(L_h = 1.5\). When deployed to a new regional hospital, continuous physiological sensor features exhibit a 1D Wasserstein-1 divergence of \(\mathcal{W}_1(P, Q) = 0.12\). The domain discrepancy between hospital populations is estimated at \(\Delta_{\text{disc}} = 0.04\).

    1. Calculate the theoretical upper bound on evaluation loss \(\epsilon_Q(h)\) on the new regional hospital cohort.
    2. If the clinical safety failure threshold is set at a maximum loss of \(\epsilon_{\text{max}} = 0.35\), is the model provably safe to deploy without fine-tuning?
    Reveal Detailed Solution

    Step-by-Step Derivation:

    1. Calculate Generalization Error Bound: By the Wasserstein covariate shift generalization bound (Definition 13.2.2):

    \[ \epsilon_Q(h) \le \epsilon_P(h) + 2 L_h \mathcal{W}_1(P, Q) + \Delta_{\text{disc}} \]

    Substitute the given parameter values: - \(\epsilon_P(h) = 0.06\) - \(L_h = 1.5\) - \(\mathcal{W}_1(P, Q) = 0.12\) - \(\Delta_{\text{disc}} = 0.04\)

    \[ 2 L_h \mathcal{W}_1(P, Q) = 2 \times 1.5 \times 0.12 = 3.0 \times 0.12 = 0.36 \]
    \[ \epsilon_Q(h) \le 0.06 + 0.36 + 0.04 = 0.46 \]

    The theoretical upper bound on evaluation loss on the new patient population is \(\epsilon_Q(h) \le 0.46\).

    2. Safety Gate Evaluation: The clinical safety threshold requires \(\epsilon_Q(h) \le 0.35\).

    Because the theoretical upper bound is \(0.46 > 0.35\), the model cannot be provably certified as safe for deployment on the new hospital cohort.

    Required Actions: 1. Mandate domain adaptation or transfer learning using unlabelled target domain data to compress \(\mathcal{W}_1(P, Q) \le \frac{0.35 - 0.06 - 0.04}{3.0} = \frac{0.25}{3.0} \approx 0.083\). 2. Recalibrate feature extraction pipelines to standardize sensor gain and patient posture prior to inference.

    🎯 Conceptual Overview & Causal Architecture

    Supervised machine learning and foundation model alignment depend on millions of accurately annotated training signals. While self-supervised pretraining and synthetic generation help mitigate scarcity, human judgment remains the canonical ground truth for nuanced semantics, visual boundaries, safety evaluations, and ambiguous edge cases (Snow et al., 2008; Deng et al., 2009). Crowdsourcing transforms annotation into an elastically scalable primitive by decomposing complex labeling objectives into Human Intelligence Tasks (HITs) routed across distributed workforces (Kittur et al., 2008; Peer et al., 2017).

    Because individual crowd annotators exhibit heterogeneous skill, fatigue, and occasional adversarial noise, raw crowd labels cannot be ingested directly. High-reliability systems pair Active Uncertainty Sampling (Settles, 2012) with Inter-Annotator Agreement Audits (Artstein & Poesio, 2008) and Latent Worker Reliability Models (Dawid & Skene, 1979; Ipeirotis et al., 2010) to extract high-purity consensus labels at minimal budget.

    📐 Mathematical Formulations & Theoretical Derivations

    To convert noisy non-expert judgments into research-grade training benchmarks, we formalize majority consensus convergence limits, active query acquisition functions, chance-corrected inter-annotator agreement, and probabilistic worker confusion inference.

    Definition 9.2.1 (Condorcet's Jury Theorem & Anti-Condorcet Regime)

    Suppose \(n = 2m + 1\) independent workers label a binary item with homogeneous competence probability \(p = P(\hat{y}_w = y_{\text{true}}) \in [0, 1]\). Under unweighted majority voting, the probability that the aggregated label matches truth is the exact binomial upper tail (Snow et al., 2008):

    \[ P_{\text{majority}}(n, p) = \sum_{k=m+1}^{2m+1} \binom{2m+1}{k} p^k (1 - p)^{2m+1-k} \]

    By Hoeffding's inequality, consensus error decays exponentially with pool size \(n\) whenever competence strictly exceeds random guessing (\(p > 0.50\)):

    \[ 1 - P_{\text{majority}}(n, p) \le \exp\!\left( -2n \left(p - \frac{1}{2}\right)^2 \right) \quad \Longrightarrow \quad \lim_{n \to \infty} P_{\text{majority}}(n, p) = 1 \quad (\forall\, p > 0.50) \]

    Conversely, if spammers or ambiguous instructions pull competence below random chance (\(p < 0.50\)), adding redundant workers induces Anti-Condorcet Inversion, driving ensemble accuracy monotonically toward \(0\). Furthermore, if workers share systemic instruction biases (inter-worker correlation \(\rho_{\text{corr}} > 0\)), consensus accuracy plateaus below \(1.0\) regardless of pool size.

    Worked Numerical Example: For moderately noisy workers with competence \(p = 0.65\): - With \(n = 9\) redundant annotators: \(P_{\text{majority}}(9, 0.65) = 0.8283\) (\(82.83\%\)). - With \(n = 25\) annotators: \(P_{\text{majority}}(25, 0.65) = 0.9396\) (\(93.96\%\), still below a \(95\%\) SLA). - Crossing a strict \(95\%\) accuracy ceiling at \(p = 0.65\) requires \(n = 29\) workers: \(P_{\text{majority}}(29, 0.65) = 0.9524\) (\(95.24\%\)). - Under adversarial noise (\(p = 0.40\)), \(n = 9\) workers yield only \(26.66\%\) accuracy!

    Definition 9.2.2 (Shannon Entropy Uncertainty Sampling & Budget Compression)

    Rather than annotating random unlabeled records where a classifier checkpoint \(\theta\) is already confident, Active Uncertainty Sampling prioritizes candidates \(x \in \mathcal{U}\) maximizing conditional prediction entropy (Settles, 2012):

    \[ x^* = \arg\max_{x \in \mathcal{U}} H_\theta(Y \mid x) = \arg\max_{x \in \mathcal{U}} \left( - \sum_{y \in \mathcal{Y}} P_\theta(y \mid x) \log_2 P_\theta(y \mid x) \right) \]

    where \(0 \le H_\theta(Y \mid x) \le \log_2 |\mathcal{Y}|\) bits. Concentrating human labeling budgets along high-entropy decision boundaries routinely achieves identical downstream generalization F1 scores using \(60\% - 80\%\) fewer HITs than uniform random sampling.

    Worked Entropy Calculation (Binary Class Posteriors): - Confident example \(P = [0.99, 0.01]\): \(H = -0.99\log_2(0.99) - 0.01\log_2(0.01) = 0.0808\text{ bits}\) (skip crowd annotation). - Moderate example \(P = [0.80, 0.20]\): \(H = 0.7219\text{ bits}\). - Decision-boundary example \(P = [0.51, 0.49]\): \(H = 0.9997\text{ bits} \approx 1.00\text{ bit}\) (route immediately to HIT queue).

    Definition 9.2.3 (Fleiss' Kappa Agreement & The Prevalence Paradox)

    When measuring consensus among \(n\) fixed annotators per item across \(N\) subjects and \(k\) categorical labels—letting \(n_{ij}\) denote how many raters assigned item \(i\) to category \(j\)—chance-corrected agreement is Fleiss' Kappa \(\kappa\) (Artstein & Poesio, 2008):

    \[ \kappa = \frac{\bar{P} - \bar{P}_e}{1 - \bar{P}_e} \]

    where observed pair-wise agreement \(\bar{P}\) and expected chance agreement \(\bar{P}_e\) are:

    \[ \bar{P} = \frac{1}{N n (n - 1)} \sum_{i=1}^N \sum_{j=1}^k n_{ij}(n_{ij} - 1), \qquad \bar{P}_e = \sum_{j=1}^k \left( \frac{1}{N n} \sum_{i=1}^N n_{ij} \right)^2 \]

    Worked Calculation & Fleiss' Paradox: Given \(N = 5\) items and \(n = 3\) raters with tally matrix \([[3,0], [3,0], [0,3], [0,3], [2,1]]\): - Per-item agreement vector: \(P_i = [1.0, 1.0, 1.0, 1.0, 0.3333] \implies \bar{P} = 0.8667\). - Class marginals: \(p_1 = \frac{8}{15}, p_2 = \frac{7}{15} \implies \bar{P}_e = (\frac{8}{15})^2 + (\frac{7}{15})^2 = 0.5022\). - Resulting Kappa: \(\kappa = \frac{0.8667 - 0.5022}{1 - 0.5022} = 0.7321\) (Substantial Agreement). By contrast, [[3,0],[3,0],[0,3],[2,1],[1,2]] drops to \(\bar{P} = 0.7333, \bar{P}_e = 0.5200 \implies \kappa = 0.4444\) (Moderate Agreement). Be mindful of Feinstein-Cicchetti Prevalence Paradox: under rare classes (\(95\%\) / \(5\%\) skew), \(\bar{P}_e \to 0.905\), compressing \(\kappa\) downward even when raw agreement exceeds \(92\%\).

    Definition 9.2.4 (Dawid-Skene Worker Confusion Matrix & Campaign Budgeting)

    Unweighted majority vote assigns identical trust to domain experts, careless guessers (\(p = 0.50\)), and systematic adversarial bots (\(p < 0.25\)). The Dawid-Skene Generative Model (Dawid & Skene, 1979; Ipeirotis et al., 2010) assigns each worker \(w\) a latent confusion matrix \(\pi_{c,\ell}^{(w)} = P(\text{vote}_w = \ell \mid y_{\text{true}} = c)\) alongside class prior \(q_c\), computing exact Maximum A Posteriori class log-odds:

    \[ \hat{y}_i = \arg\max_{c \in \mathcal{Y}} \left[ \ln q_c + \sum_{w \in \mathcal{W}_i} \ln \pi_{c, \ell_{i,w}}^{(w)} \right] \]

    Notice a fundamental insight: a malicious worker who systematically flips labels (\(\pi_{1,0}^{(w)} = 0.85, \pi_{0,1}^{(w)} = 0.85\)) actually carries negative mutual certainty that Dawid-Skene inverts cleanly into useful signal, whereas a random clicker (\(\pi_{c,\ell}^{(w)} = 0.50\)) receives zero log-odds weight! Operational campaign spend including hidden Gold-Unit qualification overhead fraction \(\alpha_{\text{gold}}\) and redundancy \(n\) equals:

    \[ C_{\text{total}} = N_{\text{items}} \cdot n \cdot \left(1 + \alpha_{\text{gold}}\right) \cdot c_{\text{HIT}} \]

    Industrial Best Practice: Task Decomposition into Atomic Micro-Tasks

    Deconstruct complex annotation schemas into self-contained atomic micro-tasks taking \(15 - 45\) seconds per HIT. Breaking full-document audits into sentence-level or single-span tagging measurably raises crowd accuracy and stabilizes inter-rater agreement (\(\kappa > 0.75\)).

    Common Pitfall / Anti-Pattern: Open-Ended Subjective Prompts Without Rubrics

    Deploying vague instructions such as "Is this text high quality?" without concrete boundary examples yields near-chance agreement (\(\kappa < 0.20\)). Pair every HIT template with unambiguous decision trees and anchor gold-standard illustrations.

    💻 Runnable Executable Python Implementation

    The following Pydantic V2 verification suite (CrowdsourcingEngine) evaluates:

    1. Condorcet Jury scaling across moderate (\(p=0.65\)), strict SLA (\(n=29 \to 95.24\%\)), and Anti-Condorcet (\(p=0.40\)) regimes.
    2. Shannon Entropy uncertainty selection across batch posterior arrays.
    3. Fleiss' Kappa across both Moderate (\(\kappa = 0.4444\)) and Substantial (\(\kappa = 0.7321\)) annotation matrices.
    4. Dawid-Skene log-odds consensus recovery outperforming naive majority voting against a systematic label flipper, plus Campaign Budget accounting.
    """
Lesson 9.2 Verification Suite: Condorcet Jury, Active Entropy, Fleiss' Kappa & Dawid-Skene
Verified against Dawid & Skene (1979), Snow et al. (2008), Artstein & Poesio (2008), Settles (2012).
"""

import math
from typing import Dict, List, Tuple
import numpy as np
from pydantic import BaseModel, Field


class CondorcetReport(BaseModel):
    n_workers: int = Field(..., gt=0)
    worker_accuracy: float = Field(..., ge=0.0, le=1.0)
    majority_accuracy: float
    hoeffding_error_bound: float
    above_chance: bool


class ActiveQueryReport(BaseModel):
    candidate_entropies_bits: List[float]
    selected_indices: List[int]
    max_entropy_bits: float


class AgreementReport(BaseModel):
    n_items: int
    n_raters: int
    observed_agreement_pbar: float
    chance_agreement_pe: float
    fleiss_kappa: float


class DawidSkeneBudgetReport(BaseModel):
    majority_vote_prediction: int
    dawid_skene_prediction: int
    class_log_posteriors: Dict[int, float]
    total_budget_usd: float


class CrowdsourcingEngine:
    """Calculates Condorcet consensus, active query entropy, Fleiss' Kappa & Dawid-Skene log-odds."""

    @staticmethod
    def evaluate_condorcet(n_workers: int, worker_accuracy: float) -> CondorcetReport:
        assert n_workers % 2 == 1, "n_workers must be odd for unambiguous binary majority!"
        m = (n_workers - 1) // 2
        prob = sum(
            math.comb(n_workers, k) * (worker_accuracy ** k) * ((1.0 - worker_accuracy) ** (n_workers - k))
            for k in range(m + 1, n_workers + 1)
        )
        bound = math.exp(-2.0 * n_workers * ((worker_accuracy - 0.5) ** 2)) if worker_accuracy > 0.5 else 1.0
        return CondorcetReport(
            n_workers=n_workers,
            worker_accuracy=worker_accuracy,
            majority_accuracy=round(prob, 6),
            hoeffding_error_bound=round(min(1.0, bound), 6),
            above_chance=worker_accuracy > 0.50,
        )

    @staticmethod
    def select_active_learning_queries(probabilities: np.ndarray, top_k: int = 1) -> ActiveQueryReport:
        p = np.clip(probabilities, 1e-12, 1.0)
        entropies = -np.sum(p * np.log2(p), axis=1)
        selected = np.argsort(entropies)[::-1][:top_k]
        return ActiveQueryReport(
            candidate_entropies_bits=[round(float(e), 4) for e in entropies],
            selected_indices=selected.tolist(),
            max_entropy_bits=round(float(np.max(entropies)), 4),
        )

    @staticmethod
    def evaluate_fleiss_kappa(ratings_matrix: np.ndarray) -> AgreementReport:
        n_items, _ = ratings_matrix.shape
        n_raters = int(np.sum(ratings_matrix[0, :]))
        p_j = np.sum(ratings_matrix, axis=0) / (n_items * n_raters)
        p_e = float(np.sum(p_j ** 2))
        p_i = (np.sum(ratings_matrix ** 2, axis=1) - n_raters) / (n_raters * (n_raters - 1))
        p_bar = float(np.mean(p_i))
        kappa = 1.0 if math.isclose(p_e, 1.0) else (p_bar - p_e) / (1.0 - p_e)
        return AgreementReport(
            n_items=n_items,
            n_raters=n_raters,
            observed_agreement_pbar=round(p_bar, 4),
            chance_agreement_pe=round(p_e, 4),
            fleiss_kappa=round(float(kappa), 4),
        )

    @staticmethod
    def evaluate_dawid_skene_and_budget(
        priors: Dict[int, float],
        worker_confusions: List[Dict[Tuple[int, int], float]],
        votes: List[int],
        n_items: int,
        redundancy: int,
        alpha_gold: float,
        cost_per_hit_usd: float,
    ) -> DawidSkeneBudgetReport:
        maj_pred = 1 if sum(votes) > (len(votes) / 2.0) else 0
        log_posts: Dict[int, float] = {}
        for c, q_c in priors.items():
            score = math.log(q_c)
            for conf, v_w in zip(worker_confusions, votes):
                score += math.log(max(1e-9, conf[(c, v_w)]))
            log_posts[c] = round(score, 4)
        ds_pred = max(log_posts.items(), key=lambda kv: kv[1])[0]
        total_cost = n_items * redundancy * (1.0 + alpha_gold) * cost_per_hit_usd
        return DawidSkeneBudgetReport(
            majority_vote_prediction=maj_pred,
            dawid_skene_prediction=ds_pred,
            class_log_posteriors=log_posts,
            total_budget_usd=round(total_cost, 2),
        )


# =====================================================================
# Verification & Execution Benchmark
# =====================================================================
if __name__ == "__main__":
    print("=" * 68)
    print("TRACK 9.2 CROWDSOURCING CONSENSUS & ACTIVE LEARNING SUITE")
    print("=" * 68)

    engine = CrowdsourcingEngine()

    # 1. Condorcet Jury Verification (p=0.65 across n=9, 25, 29; plus p=0.40 inversion)
    c9 = engine.evaluate_condorcet(n_workers=9, worker_accuracy=0.65)
    c25 = engine.evaluate_condorcet(n_workers=25, worker_accuracy=0.65)
    c29 = engine.evaluate_condorcet(n_workers=29, worker_accuracy=0.65)
    c_anti = engine.evaluate_condorcet(n_workers=9, worker_accuracy=0.40)

    print(f"[AUDIT] Condorcet n=9,  p=0.65 -> {c9.majority_accuracy * 100:.2f}%")
    print(f"[AUDIT] Condorcet n=25, p=0.65 -> {c25.majority_accuracy * 100:.2f}%")
    print(f"[AUDIT] Condorcet n=29, p=0.65 -> {c29.majority_accuracy * 100:.2f}% (>95% SLA)")
    print(f"[AUDIT] Anti-Condorcet n=9, p=0.40 -> {c_anti.majority_accuracy * 100:.2f}% (inversion collapse)")
    assert math.isclose(c9.majority_accuracy, 0.828281, abs_tol=1e-4)
    assert math.isclose(c25.majority_accuracy, 0.939555, abs_tol=1e-4)
    assert c29.majority_accuracy > 0.95
    assert c_anti.majority_accuracy < 0.30 and c_anti.above_chance is False

    # 2. Active Learning Shannon Entropy Query Selection
    probs = np.array([[0.99, 0.01], [0.51, 0.49], [0.80, 0.20]])
    q_rep = engine.select_active_learning_queries(probs, top_k=1)
    print(f"[AUDIT] Active Query Entropies: {q_rep.candidate_entropies_bits} bits -> selected index {q_rep.selected_indices}")
    assert q_rep.selected_indices == [1]
    assert math.isclose(q_rep.max_entropy_bits, 0.9997, abs_tol=1e-3)

    # 3. Fleiss' Kappa Verification (Moderate vs Substantial Agreement)
    mat_mod = np.array([[3, 0], [3, 0], [0, 3], [2, 1], [1, 2]])
    mat_sub = np.array([[3, 0], [3, 0], [0, 3], [0, 3], [2, 1]])
    k_mod = engine.evaluate_fleiss_kappa(mat_mod)
    k_sub = engine.evaluate_fleiss_kappa(mat_sub)
    print(f"[AUDIT] Fleiss Kappa Moderate: {k_mod.fleiss_kappa} | Substantial: {k_sub.fleiss_kappa}")
    assert math.isclose(k_mod.fleiss_kappa, 0.4444, abs_tol=1e-3)
    assert math.isclose(k_sub.fleiss_kappa, 0.7321, abs_tol=1e-3)

    # 4. Dawid-Skene Inversion Rescue vs Unweighted Majority + Budget
    # True class = 1. Votes = [1 (Expert p=0.90), 0 (Noisy p=0.55), 0 (Systematic Flipper acc=0.15)]
    worker_a = {(1, 1): 0.90, (1, 0): 0.10, (0, 0): 0.90, (0, 1): 0.10}
    worker_b = {(1, 1): 0.55, (1, 0): 0.45, (0, 0): 0.55, (0, 1): 0.45}
    worker_c = {(1, 1): 0.15, (1, 0): 0.85, (0, 0): 0.15, (0, 1): 0.85}
    ds_rep = engine.evaluate_dawid_skene_and_budget(
        priors={0: 0.5, 1: 0.5},
        worker_confusions=[worker_a, worker_b, worker_c],
        votes=[1, 0, 0],
        n_items=10000,
        redundancy=5,
        alpha_gold=0.10,
        cost_per_hit_usd=0.05,
    )
    print(f"[AUDIT] Votes=[1,0,0] -> Majority={ds_rep.majority_vote_prediction} (WRONG) vs Dawid-Skene={ds_rep.dawid_skene_prediction} (RESCUED)")
    print(f"[AUDIT] Dawid-Skene Log-Posteriors: {ds_rep.class_log_posteriors} | Budget=${ds_rep.total_budget_usd:,.2f}")
    assert ds_rep.majority_vote_prediction == 0
    assert ds_rep.dawid_skene_prediction == 1
    assert ds_rep.total_budget_usd == 2750.00

    Case Study 1: Galaxy Zoo & Citizen Science Astronomical Annotation

    Astrophysics surveys show how non-expert crowds paired with statistical consensus match specialist expert fidelity at continental scale:

    Sloan Digital Sky Survey (SDSS) & Galaxy Zoo Consensus Weighting

    • The Bottleneck: The Sloan Digital Sky Survey photographed over 1 Million distant galaxies; manual morphological classification (spiral, elliptical, merger) by a lone astrophysicist would require 124 uninterrupted years.
    • The Crowdsourcing Design: Galaxy Zoo decomposed visual inspection into a structured 6-button decision tree routed to 150,000 citizen volunteers, collecting an average of 38 independent classifications per image (Kittur et al., 2008).
    • The Statistical Output: Weighting volunteer votes by consistency against gold calibration tiles achieved 98.4% agreement with professional Hubble Space Telescope benchmarks, fueling hundreds of peer-reviewed discoveries.

    Case Study 2: ImageNet Scale Visual Taxonomy & Adversarial Crowd Filtering

    Building the benchmark that ignited modern deep vision required solving quality control across tens of thousands of simultaneous remote workers:

    ImageNet 14.2M-Image Acquisition & Dynamic Redundancy Control

    • The Combinatorial Challenge: Curating 14.2 Million labeled images across 21,841 fine-grained WordNet synsets (distinguishing 120 dog breeds rather than generic animals) exceeded internal university graduate labor capacity by orders of magnitude (Deng et al., 2009).
    • Adversarial Failure Modes on Open Markets: Without quality gates, automated click-bots and careless MTurk raters exploit bulk image grids ($p \approx 0.50$), dragging naive majority votes into near-random noise (Snow et al., 2008).
    • The Engineering Defense: ImageNet engineers embedded hidden Gold-Standard Sentinel Images per HIT grid, estimated category-specific difficulty, and dynamically scaled redundancy thresholds ($n \in [3, 10]$) using probabilistic confidence scoring—achieving $99.7\%$ precision on fine-grained classes (Ipeirotis et al., 2010).

    ❓ Interactive Self-Assessment Micro-Checks

    Self-Assessment 1: Condorcet Convergence vs. Anti-Condorcet Inversion

    Suppose you recruit an ensemble of \(n = 9\) independent workers to classify medical chest X-rays. Compare the exact consensus accuracy when individual worker competence is \(p = 0.65\) versus an adversarial click-bot cohort where workers systematically misread reversed instructions (\(p = 0.40\)). What happens as you keep scaling \(n \to \infty\) in both regimes?

    Reveal Detailed Solution

    Answer: Applying the binomial majority sum \(P_{\text{majority}}(n, p) = \sum_{k=m+1}^{2m+1} \binom{2m+1}{k} p^k (1-p)^{2m+1-k}\):

    1. At \(p = 0.65\) (\(n = 9\)): \(P_{\text{majority}}(9, 0.65) \approx 82.83\%\). Scaling to \(n = 29\) lifts majority accuracy past \(95.24\%\), converging monotonically toward \(100\%\) as \(n \to \infty\).
    2. At \(p = 0.40\) (\(n = 9\)): \(P_{\text{majority}}(9, 0.40) \approx 26.66\%\). Because competence lies below \(0.50\), Anti-Condorcet inversion accelerates error toward \(0\%\) accuracy as more noisy workers are added!
    Self-Assessment 2: Worker Specialization vs. Anonymous Generalist Crowds

    In crowdsourced pixel-level semantic segmentation for autonomous vehicle perception scenes (drivable lanes, vulnerable cyclists, traffic signals), why do trained, persistent managed workforces systematically outperform anonymous public micro-task crowds?

    Reveal Detailed Solution

    Answer: High-precision geometric labeling introduces edge-snapping rules that cannot be conveyed in a 20-second task card:

    1. Managed annotation teams complete multi-week codebook onboarding and direct feedback loops with perception engineers, driving per-worker competence \(p \gt 0.90\) and Fleiss' \(\kappa \gt 0.85\).
    2. Anonymous public crowds exhibit rapid worker churn, variable monitor calibration, and susceptibility to correlated rubric misunderstandings, creating systematic boundary jitter that degrades downstream mIoU.
    Self-Assessment 3: Solving the Cold Start & Click-Bot Problem via Gold Sentinels

    Why should every newly launched crowdsourcing campaign combine a Qualification Exam Gate upfront with continuous Hidden Gold-Unit Sentinels injected inside live HIT batches?

    Reveal Detailed Solution

    Answer: Upfront Qualification Exams block low-effort bots and misaligned raters before a single production dollar is spent. However, vetted human workers still suffer mid-session fatigue or begin speed-clicking after batch #50.

    Injecting \(10\%\) known ground-truth sentinel tasks randomly into live production streams supplies unbiased real-time confusion estimates \(\hat{\pi}_{c,\ell}^{(w)}\) for Dawid-Skene weighting and triggers automatic throttling if competence drifts below acceptance bounds.

    Self-Assessment 4: Recovering Signal from Systematic Flippers vs. Pure Spammers

    Under the Dawid-Skene probabilistic model, suppose Worker X answers randomly (\(p = 0.50\)) while Worker Y misinterprets binary labels and systematically flips them (\(p = 0.10\), getting \(90\%\) wrong). Which worker carries higher statistical value once calibrated against gold units, and why?

    Reveal Detailed Solution

    Answer: Worker Y (\(p = 0.10\)) carries far higher statistical value!

    Worker X injects pure white noise (\(\pi_{1,1} = \pi_{1,0} = 0.50\)), yielding zero log-odds information (\(\ln \frac{0.50}{0.50} = 0\)) and zero Shannon mutual information. By contrast, Worker Y exhibits predictable conditional inversion (\(\pi_{1,0}^{(Y)} = 0.90, \pi_{0,1}^{(Y)} = 0.90\)). Calibrating Worker Y's confusion matrix allows Dawid-Skene log-likelihood aggregation to invert every vote cleanly into a \(90\%\)-accurate indicator!

    🎯 Conceptual Overview & The Software 2.0 Shift

    In classical machine learning pipelines, human subject matter experts spend thousands of hours manually hand-labeling individual instances one by one. This hand-labeling paradigm suffers from severe systemic vulnerabilities: it is unversioned, non-auditable, prohibitively expensive, and must be discarded and repeated from scratch whenever schema taxonomies change (Ratner et al., 2016; Ratner et al., 2017). When business requirements or class boundaries evolve, thousands of hand-labeled records become technical debt.

    Weak Supervision revolutionizes data curation by shifting from manual instance-level labeling to programmatic data programming (Ratner et al., 2017). Instead of hand-labeling 100,000 documents, domain experts write a suite of dozens of Labeling Functions (LFs)—arbitrary Python functions that encode domain heuristics, regular expressions, pattern dictionaries, automated rule synthesis (Varma & Ré, 2018), ontology-guided clinical extractions (Fries et al., 2021), distant supervision lookups, and zero-shot foundation model prompts (Bach et al., 2019; Zhang et al., 2021). Fast covariance parameter estimation models such as FlyingSquid further enable near-instantaneous scaling over millions of samples (Chen et al., 2020).

    The Software 2.0 Paradigm: Code-as-Supervision

    In Software 2.0, training data is no longer curated through manual, subjective point clicks in a third-party labeling portal. Instead, supervision is expressed as executable software programs that are subject to the same rigorous engineering lifecycle as application code: version control via Git, continuous integration, regression testing, and collaborative pull requests (Ratner et al., 2017; Varma et al., 2019).

    Anatomy of a Labeling Function (LF)

    A Labeling Function (LF) \(\lambda_j\) takes an unlabeled instance \(\mathbf{x} \in \mathcal{X}\) and either outputs a predicted class label or abstains (\(0\)):

    \[ \lambda_j(\mathbf{x}): \mathcal{X} \to \{-1, 0, 1\} \quad \text{or} \quad \{1, 2, \dots, K\} \cup \{0\} \]
    • Abstention is Foundational: Unlike a traditional classifier which must emit a guess on every instance, an LF acts only when its specific heuristic pattern is detected. For example, a regex rule detecting clinical drug names abstains on 98% of medical text records and votes only when an explicit drug token is present.
    • Noise Tolerance: Individual LFs are expected to be noisy (typically \(60\% - 85\%\) accuracy), correlate with one another, and frequently disagree.
    • Generative Label Modeling: A statistical factor graph models the joint distribution of observed LF votes and the unobserved latent true label, estimating LF accuracies without requiring ground-truth gold labels (Ratner et al., 2016; Chen et al., 2020).

    Industrial Best Practice: Programmatic Labeling with Snorkel

    Replace manual token-by-token labeling with Programmatic Weak Supervision: author 20–50 deterministic Labeling Functions (LFs) capturing domain heuristics, regex patterns, external dictionaries, and zero-shot model outputs. Snorkel estimates rule accuracies and outputs probabilistic training labels automatically.

    Common Pitfall / Anti-Pattern: Majority Voting Over Correlated Labeling Rules

    If five labeling functions depend on the exact same keyword list or sentiment lexicon, a naive majority vote counts their correlated vote five times, artificially inflating confidence and overpowering independent, accurate rules. Always use a generative model that explicitly accounts for conditional covariance between labeling functions (Ratner et al., 2017; Varma et al., 2019).

    📐 Formal Mathematical Definitions

    Definition 11.5.1: The Sparse Label Matrix \(\mathbf{\Lambda}\) and Data Programming Formulations

    Let \(\mathcal{X} = \{\mathbf{x}_1, \dots, \mathbf{x}_n\}\) denote an unlabeled dataset drawn from an underlying data distribution \(\mathcal{D}_{\mathcal{X}}\), where each instance has an unobserved latent true label \(y_i^* \in \mathcal{Y} = \{-1, +1\}\) (or \(K\)-ary \(\mathcal{Y} = \{1, \dots, K\}\)). Let \(\boldsymbol{\lambda} = (\lambda_1, \dots, \lambda_m)^T\) denote an ensemble of \(m\) labeling functions, where each function is a mapping:

    \[ \lambda_j: \mathcal{X} \to \{-1, 0, +1\} \quad (j = 1, \dots, m) \]

    with \(\lambda_j(\mathbf{x}_i) = 0\) designating that labeling function \(\lambda_j\) abstains on sample \(\mathbf{x}_i\).

    Evaluating the ensemble \(\boldsymbol{\lambda}\) across all \(n\) unlabeled instances generates the Sparse Label Matrix \(\mathbf{\Lambda} \in \{-1, 0, +1\}^{n \times m}\):

    \[ \mathbf{\Lambda} = \begin{bmatrix} \Lambda_{1, 1} & \Lambda_{1, 2} & \dots & \Lambda_{1, m} \\ \Lambda_{2, 1} & \Lambda_{2, 2} & \dots & \Lambda_{2, m} \\ \vdots & \vdots & \ddots & \vdots \\ \Lambda_{n, 1} & \Lambda_{n, 2} & \dots & \Lambda_{n, m} \end{bmatrix} = \begin{bmatrix} \lambda_1(\mathbf{x}_1) & \lambda_2(\mathbf{x}_1) & \dots & \lambda_m(\mathbf{x}_1) \\ \lambda_1(\mathbf{x}_2) & \lambda_2(\mathbf{x}_2) & \dots & \lambda_m(\mathbf{x}_2) \\ \vdots & \vdots & \ddots & \vdots \\ \lambda_1(\mathbf{x}_n) & \lambda_2(\mathbf{x}_n) & \dots & \lambda_m(\mathbf{x}_n) \end{bmatrix} \]

    The non-zero entries of \(\mathbf{\Lambda}\) define the empirical support mask \(\mathbf{S} \in \{0, 1\}^{n \times m}\), where \(S_{i, j} = \mathbb{I}(\Lambda_{i, j} \ne 0)\). In industrial applications, \(\mathbf{\Lambda}\) is highly sparse: each individual LF covers only a small fraction of the input space (\(1\% - 40\%\)), but their union spans the vast majority of the corpus.

    Definition 11.5.2: Labeling Function Matrix Metrics (Coverage, Overlap, Conflict, and Empirical Accuracy)

    For any ensemble of labeling functions \(\boldsymbol{\lambda}\) evaluated over corpus \(\mathcal{X}\), the structural properties of \(\mathbf{\Lambda}\) are governed by four fundamental mathematical metrics:

    1. Individual LF Coverage: The empirical fraction of instances where labeling function \(\lambda_j\) emits a non-abstaining vote:

      \[ \operatorname{Cov}(\lambda_j) = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(\Lambda_{i, j} \ne 0) = \frac{1}{n} \|\mathbf{\Lambda}_{:, j}\|_0 \]

    2. Total Pipeline Coverage: The proportion of instances labeled by at least one labeling function in the ensemble:

      \[ \operatorname{Cov}_{\text{total}}(\boldsymbol{\lambda}) = \frac{1}{n} \sum_{i=1}^n \mathbb{I}\left( \sum_{j=1}^m |\Lambda_{i, j}| > 0 \right) \]

    3. Pairwise Overlap Matrix \(\mathbf{O} \in [0, 1]^{m \times m}\): The frequency with which two labeling functions \(\lambda_j\) and \(\lambda_k\) simultaneously emit votes on the same instance:

      \[ O_{j, k} = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(\Lambda_{i, j} \ne 0 \ \land \ \Lambda_{i, k} \ne 0) \]

    4. Pairwise Conflict Matrix \(\mathbf{C} \in [0, 1]^{m \times m}\): The frequency with which two labeling functions both vote on an instance but disagree on the assigned label:

      \[ C_{j, k} = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(\Lambda_{i, j} \ne 0 \ \land \ \Lambda_{i, k} \ne 0 \ \land \ \Lambda_{i, j} \ne \Lambda_{i, k}) \]

    5. Empirical Validation Accuracy: Given a small held-out gold validation set \(\mathcal{D}_{\text{val}} = \{(\mathbf{x}_k, y_k^*)\}_{k=1}^{n_v}\), the empirical precision of \(\lambda_j\) on its covered slice is:

      \[ \operatorname{Acc}_{\text{emp}}(\lambda_j) = \frac{\sum_{k=1}^{n_v} \mathbb{I}(\lambda_j(\mathbf{x}_k) = y_k^*)}{\sum_{k=1}^{n_v} \mathbb{I}(\lambda_j(\mathbf{x}_k) \ne 0)} \]

    High conflict ratios \(C_{j, k}\) indicate decision-boundary ambiguity or contradictory heuristic definitions, providing the critical statistical leverage necessary for unsupervised generative models to infer rule reliability (Ratner et al., 2017).

    Definition 11.5.3: Generative Label Model & Latent Factor Estimation (Snorkel / Gibbs / Ising Model)

    Let \(Y \in \{-1, +1\}\) denote the latent true binary label and \(\mathbf{\Lambda} = (\Lambda_1, \dots, \Lambda_m)^T \in \{-1, 0, +1\}^m\) denote the observed LF votes for a single instance. In data programming (Ratner et al., 2016), the joint probability distribution \(\mathbb{P}_{\boldsymbol{\theta}}(\mathbf{\Lambda}, Y)\) is parameterized as a factor graph (Gibbs / Ising distribution):

    \[ \mathbb{P}_{\boldsymbol{\theta}}(\mathbf{\Lambda}, Y) = \frac{1}{Z_{\boldsymbol{\theta}}} \exp\left( \sum_{j=1}^m \theta_j^{\text{acc}} \Lambda_j Y + \sum_{j=1}^m \theta_j^{\text{prop}} |\Lambda_j| + \sum_{(j, k) \in \mathcal{E}} \theta_{jk}^{\text{corr}} \Lambda_j \Lambda_k \right) \]

    where: - \(\theta_j^{\text{acc}} \in \mathbb{R}\) is the accuracy parameter for LF \(\lambda_j\) (governing alignment with the true label \(Y\)). - \(\theta_j^{\text{prop}} \in \mathbb{R}\) is the propensity parameter governing the baseline frequency of non-abstention. - \(\theta_{jk}^{\text{corr}} \in \mathbb{R}\) is the correlation weight across an edge set \(\mathcal{E}\) capturing statistical dependencies between heuristics. - \(Z_{\boldsymbol{\theta}}\) is the partition function normalizing the probability distribution:

    \[ Z_{\boldsymbol{\theta}} = \sum_{y \in \{-1, +1\}} \sum_{\boldsymbol{\lambda} \in \{-1, 0, +1\}^m} \exp\left( \sum_{j=1}^m \theta_j^{\text{acc}} \lambda_j y + \sum_{j=1}^m \theta_j^{\text{prop}} |\lambda_j| + \sum_{(j, k) \in \mathcal{E}} \theta_{jk}^{\text{corr}} \lambda_j \lambda_k \right) \]

    Unsupervised Parameter Estimation: Under conditional independence or chordal dependency graphs, parameters \(\boldsymbol{\theta}^*\) can be estimated without access to ground-truth labels \(y^*\) by minimizing the negative marginal log-likelihood of the observed label matrix:

    \[ \boldsymbol{\theta}^* = \arg\min_{\boldsymbol{\theta}} -\sum_{i=1}^n \log \mathbb{P}_{\boldsymbol{\theta}}(\mathbf{\Lambda}_{i, :}) = \arg\min_{\boldsymbol{\theta}} -\sum_{i=1}^n \log \left( \sum_{y \in \{-1, +1\}} \mathbb{P}_{\boldsymbol{\theta}}(\mathbf{\Lambda}_{i, :}, Y = y) \right) \]

    Alternatively, fast matrix completion algorithms match the empirical second-order covariance of LF outputs \(\hat{\boldsymbol{\Sigma}}_{\mathbf{\Lambda}} = \frac{1}{n} \mathbf{\Lambda}^T \mathbf{\Lambda} - \boldsymbol{\mu}_{\mathbf{\Lambda}} \boldsymbol{\mu}_{\mathbf{\Lambda}}^T\) to solve for latent accuracies in closed form or via Expectation-Maximization (Chen et al., 2020).

    The model outputs soft probabilistic training labels \(\tilde{y}_i \in [0, 1]\):

    \[ \tilde{y}_i = \mathbb{P}_{\boldsymbol{\theta}^*}(Y_i = +1 \mid \mathbf{\Lambda}_{i, :}) = \frac{\mathbb{P}_{\boldsymbol{\theta}^*}(\mathbf{\Lambda}_{i, :}, Y_i = +1)}{\mathbb{P}_{\boldsymbol{\theta}^*}(\mathbf{\Lambda}_{i, :}, Y_i = +1) + \mathbb{P}_{\boldsymbol{\theta}^*}(\mathbf{\Lambda}_{i, :}, Y_i = -1)} \]

    Definition 11.5.4: Generalization Bounds of Weakly Supervised End Models (Noise-Tolerant Loss & Sample Complexity)

    Let \(f_{\mathbf{w}}: \mathcal{X} \to \mathbb{R}\) be a discriminative deep neural network parameterized by \(\mathbf{w}\) from hypothesis class \(\mathcal{H}\) with empirical Rademacher complexity \(\mathcal{R}_n(\mathcal{H})\). Instead of training on unobserved ground truth labels \(y_i^*\), the end model is trained by minimizing the soft cross-entropy risk over the probabilistic labels \(\tilde{y}_i\):

    \[ \hat{\mathcal{L}}_{\text{soft}}(\mathbf{w}) = -\frac{1}{n} \sum_{i=1}^n \left[ \tilde{y}_i \log \sigma(f_{\mathbf{w}}(\mathbf{x}_i)) + (1 - \tilde{y}_i) \log(1 - \sigma(f_{\mathbf{w}}(\mathbf{x}_i))) \right] \]

    where \(\sigma(z) = \frac{1}{1 + e^{-z}}\) is the standard sigmoid function.

    Theorem (Data Programming Generalization Bound, Ratner et al., 2016): Let \(\mathcal{L}_{\text{true}}(\mathbf{w}) = \mathbb{E}_{(\mathbf{x}, y^*) \sim \mathcal{D}}[\ell(f_{\mathbf{w}}(\mathbf{x}), y^*)]\) denote the true risk under the clean data distribution. If the generative label model parameter estimation error satisfies \(\|\boldsymbol{\theta}^* - \boldsymbol{\theta}_0\|_2 \le \epsilon_g(m, n)\), then with probability at least \(1 - \delta\) over the random draw of \(n\) unlabeled training instances:

    \[ \mathcal{L}_{\text{true}}(\hat{\mathbf{w}}) - \inf_{\mathbf{w} \in \mathcal{H}} \mathcal{L}_{\text{true}}(\mathbf{w}) \le \mathcal{O}\left( \mathcal{R}_n(\mathcal{H}) + \sqrt{\frac{\log(1/\delta)}{n}} + \epsilon_g(m, n) + (1 - \operatorname{Cov}_{\text{total}}(\boldsymbol{\lambda})) \right) \]

    As the unlabeled dataset size \(n \to \infty\) and rule ensemble size \(m \to \infty\), the asymptotic error of the weakly supervised end model converges to the optimal Bayes risk at rate \(\mathcal{O}(n^{-1/2})\). This proves that a deep neural model trained on noisy, programmatic weak labels asymptotically matches the performance of a model trained on expensive, fully supervised human gold labels (Ratner et al., 2016; Zhang et al., 2021).

    💻 Production-Grade Python Implementation: Pydantic Weak Supervision Pipeline

    The following production script implements a complete Weak Supervision Pipeline. It defines strongly typed Pydantic V2 metadata schemas for labeling functions, compiles the sparse label matrix \(\mathbf{\Lambda}\), executes an unsupervised Expectation-Maximization Generative Label Model (Dawid-Skene / Snorkel formulation) to infer latent rule accuracies without gold supervision, benchmarks against naive majority voting, and verifies mathematical assertions:

    import re
import numpy as np
from pydantic import BaseModel, Field, ConfigDict
from typing import Callable, List, Dict, Tuple, Optional

# Label Constants: Binary Sentiment (-1: Negative, +1: Positive, 0: Abstain)
ABSTAIN = 0
POSITIVE = 1
NEGATIVE = -1

class LFMetadata(BaseModel):
    """Metadata schema defining auditability attributes for a Labeling Function."""
    model_config = ConfigDict(frozen=True)
    name: str = Field(..., description="Unique human-readable identifier for the LF")
    category: str = Field(..., description="Category: Heuristic, Regex, DistantKB, or Model")
    description: str = Field(..., description="Domain justification and pattern description")
    intended_class: int = Field(..., description="Class this rule is designed to fire on (+1 or -1)")

class LabelingFunction:
    """Encapsulates executable heuristic logic with structured provenance metadata."""
    def __init__(self, metadata: LFMetadata, func: Callable[[str], int]):
        self.metadata = metadata
        self.func = func

    def __call__(self, text: str) -> int:
        return self.func(text)

    @property
    def name(self) -> str:
        return self.metadata.name

# 1. Domain Labeling Function Implementations
def func_positive_regex(text: str) -> int:
    """Flags high-precision positive sentiment adjectives."""
    if re.search(r'\b(excellent|outstanding|superb|flawless|terrific|delightful)\b', text, re.I):
        return POSITIVE
    return ABSTAIN

def func_negative_regex(text: str) -> int:
    """Flags high-precision critical negative sentiment adjectives."""
    if re.search(r'\b(terrible|awful|horrible|defective|broken|worst|unacceptable)\b', text, re.I):
        return NEGATIVE
    return ABSTAIN

def func_short_exclamation_complaint(text: str) -> int:
    """Heuristic: short reviews with exclamation marks and negation tokens."""
    words = text.split()
    if len(words) <= 7 and "!" in text and re.search(r'\b(not|never|waste|no)\b', text, re.I):
        return NEGATIVE
    return ABSTAIN

def func_recommendation_phrase(text: str) -> int:
    """Distant phrase heuristic: explicit purchase recommendations."""
    if re.search(r'\b(highly recommend|must buy|worth every penny|five stars)\b', text, re.I):
        return POSITIVE
    return ABSTAIN

def func_noisy_overbroad_negative(text: str) -> int:
    """Intentionally noisy/overbroad heuristic flagging 'problem', 'delay', 'issue'."""
    if re.search(r'\b(problem|delay|issue|wait|cost)\b', text, re.I):
        return NEGATIVE
    return ABSTAIN

class LFMetrics(BaseModel):
    """Quality metrics for an individual labeling function."""
    coverage: float = Field(..., ge=0.0, le=1.0)
    overlaps: Dict[str, float] = Field(default_factory=dict)
    conflicts: Dict[str, float] = Field(default_factory=dict)
    inferred_accuracy: float = Field(..., ge=0.0, le=1.0)

class WeakSupervisionReport(BaseModel):
    """Comprehensive telemetry report for the entire weak supervision pipeline."""
    pipeline_coverage: float = Field(..., ge=0.0, le=1.0)
    mean_conflict_rate: float = Field(..., ge=0.0, le=1.0)
    lf_reports: Dict[str, LFMetrics] = Field(default_factory=dict)
    num_instances: int = Field(..., gt=0)
    num_lfs: int = Field(..., gt=0)

class WeakSupervisionPipeline:
    """Production weak supervision engine managing LF evaluation, metrics, and generative modeling."""

    def __init__(self, lfs: List[LabelingFunction]):
        self.lfs = lfs
        self.lf_names = [lf.name for lf in lfs]
        self.m = len(lfs)

    def build_label_matrix(self, texts: List[str]) -> np.ndarray:
        """Evaluates all M labeling functions over N unlabeled instances -> Lambda in {-1, 0, 1}^(N x M)."""
        n = len(texts)
        L = np.zeros((n, self.m), dtype=int)
        for i, text in enumerate(texts):
            for j, lf in enumerate(self.lfs):
                L[i, j] = lf(text)
        return L

    def compute_metrics(self, L: np.ndarray, inferred_accs: Optional[np.ndarray] = None) -> WeakSupervisionReport:
        """Computes coverage, pairwise overlap, pairwise conflict, and inferred accuracies."""
        n, m = L.shape
        non_abstain = (L != ABSTAIN).astype(float)
        covered_instances = np.sum(np.any(L != ABSTAIN, axis=1))
        pipe_cov = float(covered_instances / n)

        lf_reports = {}
        conflict_list = []

        if inferred_accs is None:
            inferred_accs = np.full(m, 0.70)

        for j in range(m):
            cov_j = float(np.mean(non_abstain[:, j]))
            overlaps_j = {}
            conflicts_j = {}

            for k in range(m):
                if j == k:
                    continue
                both = (non_abstain[:, j] * non_abstain[:, k]) > 0
                overlap_val = float(np.mean(both))
                conflict_val = float(np.mean(both & (L[:, j] != L[:, k])))
                overlaps_j[self.lf_names[k]] = round(overlap_val, 4)
                conflicts_j[self.lf_names[k]] = round(conflict_val, 4)
                if j < k:
                    conflict_list.append(conflict_val)

            lf_reports[self.lf_names[j]] = LFMetrics(
                coverage=round(cov_j, 4),
                overlaps=overlaps_j,
                conflicts=conflicts_j,
                inferred_accuracy=round(float(inferred_accs[j]), 4)
            )

        mean_conflict = float(np.mean(conflict_list)) if conflict_list else 0.0

        return WeakSupervisionReport(
            pipeline_coverage=round(pipe_cov, 4),
            mean_conflict_rate=round(mean_conflict, 4),
            lf_reports=lf_reports,
            num_instances=n,
            num_lfs=m
        )

    def majority_vote(self, L: np.ndarray) -> np.ndarray:
        """Baseline aggregation: unweighted sigmoid of vote sums."""
        sums = np.sum(L, axis=1)
        probs = 1.0 / (1.0 + np.exp(-sums.astype(float)))
        return probs

    def fit_generative_label_model(
        self,
        L: np.ndarray,
        max_iter: int = 50,
        tol: float = 1e-4
    ) -> Tuple[np.ndarray, np.ndarray]:
        """
        Unsupervised Generative Label Model via Expectation-Maximization (Dawid-Skene / Snorkel Formulation).
        Estimates latent class prior P(Y=1) and per-LF accuracies a_j = P(L_j = Y | L_j != 0) without ground truth.
        Enforces domain heuristic bounds (a_j in [0.55, 0.98]) to ensure symmetry breaking.
        """
        n, m = L.shape
        prior_pos = 0.5
        accs = np.full(m, 0.80)

        for iteration in range(max_iter):
            old_accs = accs.copy()

            # E-step: Compute log likelihoods for latent Y = +1 and Y = -1
            log_p_pos = np.log(prior_pos) * np.ones(n)
            log_p_neg = np.log(1.0 - prior_pos) * np.ones(n)

            for j in range(m):
                p_c = accs[j]
                p_w = 1.0 - p_c
                v_pos = (L[:, j] == POSITIVE)
                v_neg = (L[:, j] == NEGATIVE)
                log_p_pos += v_pos * np.log(p_c) + v_neg * np.log(p_w)
                log_p_neg += v_pos * np.log(p_w) + v_neg * np.log(p_c)

            max_log = np.maximum(log_p_pos, log_p_neg)
            p_pos = np.exp(log_p_pos - max_log)
            p_neg = np.exp(log_p_neg - max_log)
            posteriors = p_pos / (p_pos + p_neg)

            # Abstained samples have neutral posterior
            abstained = ~np.any(L != ABSTAIN, axis=1)
            posteriors[abstained] = 0.5

            # M-step: Update prior and accuracies
            covered = np.any(L != ABSTAIN, axis=1)
            if np.sum(covered) > 0:
                prior_pos = float(np.mean(posteriors[covered]))

            for j in range(m):
                cov_j = (L[:, j] != ABSTAIN)
                v_pos = (L[:, j] == POSITIVE)
                v_neg = (L[:, j] == NEGATIVE)
                if np.sum(cov_j) > 0:
                    exp_corr = np.sum(v_pos * posteriors + v_neg * (1.0 - posteriors))
                    accs[j] = float(np.clip(exp_corr / np.sum(cov_j), 0.55, 0.98))

            if np.max(np.abs(accs - old_accs)) < tol:
                break

        return posteriors, accs

    Self-Assessment: Label Matrix Disagreement & Covariance Structure

    Consider an unlabeled dataset with \(n = 1,000\) instances and \(m = 3\) labeling functions \(\lambda_1, \lambda_2, \lambda_3\). Suppose \(\operatorname{Cov}(\lambda_1) = 0.60\), \(\operatorname{Cov}(\lambda_2) = 0.40\), and \(\operatorname{Cov}(\lambda_3) = 0.30\). If the pairwise overlap between \(\lambda_1\) and \(\lambda_2\) is \(\operatorname{Overlap}(\lambda_1, \lambda_2) = 0.25\), and on those overlapping instances \(\lambda_1\) and \(\lambda_2\) disagree \(40\%\) of the time, calculate the pairwise Conflict Rate \(C_{1, 2}\). Furthermore, explain how the generative model utilizes this conflict to determine latent accuracies when no ground truth is provided.

    Reveal Detailed Solution

    Step 1: Calculate the Pairwise Conflict Rate \(C_{1, 2}\) By Definition 11.5.2, the pairwise conflict rate \(C_{j, k}\) is the fraction of total instances where both functions emit non-abstaining votes with opposing signs:

    \[ C_{1, 2} = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(\Lambda_{i, 1} \ne 0 \ \land \ \Lambda_{i, 2} \ne 0 \ \land \ \Lambda_{i, 1} \ne \Lambda_{i, 2}) \]

    Since the overlap is \(O_{1, 2} = 0.25\) (i.e., \(250\) instances) and the disagreement rate on the overlap is \(40\%\):

    \[ C_{1, 2} = 0.25 \times 0.40 = 0.10 \quad (10\% \text{ of the dataset, or } 100 \text{ instances}) \]

    Step 2: Unsupervised Accuracy Estimation via Covariance Triads When no ground-truth labels \(y^*\) exist, the generative model cannot evaluate individual accuracy directly. However, under conditional independence:

    \[ \mathbb{E}[\Lambda_j \Lambda_k] = \mathbb{E}[\mathbb{E}[\Lambda_j \Lambda_k \mid Y]] = \mathbb{E}[\mathbb{E}[\Lambda_j \mid Y] \mathbb{E}[\Lambda_k \mid Y]] = a_j a_k \]

    where \(a_j = \mathbb{E}[\Lambda_j Y]\) reflects the accuracy-weighted coverage of LF \(\lambda_j\). For a triad of labeling functions \((\lambda_1, \lambda_2, \lambda_3)\), we observe three empirical second-order moments:

    \[ \sigma_{12} = \mathbb{E}[\Lambda_1 \Lambda_2] \approx a_1 a_2, \quad \sigma_{23} = \mathbb{E}[\Lambda_2 \Lambda_3] \approx a_2 a_3, \quad \sigma_{13} = \mathbb{E}[\Lambda_1 \Lambda_3] \approx a_1 a_3 \]

    Solving this system of equations yields the latent accuracy of each rule in closed form:

    \[ a_1 = \sqrt{\frac{\sigma_{12} \sigma_{13}}{\sigma_{23}}}, \quad a_2 = \sqrt{\frac{\sigma_{12} \sigma_{23}}{\sigma_{13}}}, \quad a_3 = \sqrt{\frac{\sigma_{13} \sigma_{23}}{\sigma_{12}}} \]

    Thus, conflict (\(C_{1, 2} > 0\)) lowers the product \(\sigma_{12}\). If \(\lambda_1\) consistently agrees with \(\lambda_3\) while \(\lambda_2\) conflicts with \(\lambda_3\), \(\sigma_{13}\) remains high while \(\sigma_{23}\) drops, mathematically proving that \(\lambda_1\) is more reliable than \(\lambda_2\) without inspecting a single gold label!

    Self-Assessment: The Danger of Naive Majority Voting vs. Generative Soft Targets

    An unlabeled document \(\mathbf{x}_i\) receives votes from three labeling functions: \(\lambda_1(\mathbf{x}_i) = +1\), \(\lambda_2(\mathbf{x}_i) = +1\), and \(\lambda_3(\mathbf{x}_i) = -1\). Under naive majority voting, the pseudo-label is \(+1\) (by a \(2:1\) vote margin). However, our unsupervised generative model has inferred accuracies \(a_1 = 0.70\), \(a_2 = 0.65\), and \(a_3 = 0.95\). Under conditional independence and a balanced class prior \(\mathbb{P}(Y = +1) = 0.5\), calculate the exact posterior \(\mathbb{P}(Y_i = +1 \mid \mathbf{\Lambda}_i)\). Explain why training a deep neural network on this soft target prevents the catastrophic error that naive majority voting would cause.

    Reveal Detailed Solution

    Step 1: Compute Class-Conditional Likelihoods Given the observed vote vector \(\mathbf{\Lambda}_i = (+1, +1, -1)^T\):

    For latent class \(Y = +1\): - \(\lambda_1 = +1\) is correct: \(P(\Lambda_1 = +1 \mid Y = +1) = a_1 = 0.70\) - \(\lambda_2 = +1\) is correct: \(P(\Lambda_2 = +1 \mid Y = +1) = a_2 = 0.65\) - \(\lambda_3 = -1\) is an error: \(P(\Lambda_3 = -1 \mid Y = +1) = 1 - a_3 = 1 - 0.95 = 0.05\)

    \[ \mathbb{P}(\mathbf{\Lambda}_i \mid Y = +1) = 0.70 \times 0.65 \times 0.05 = 0.02275 \]

    For latent class \(Y = -1\): - \(\lambda_1 = +1\) is an error: \(P(\Lambda_1 = +1 \mid Y = -1) = 1 - a_1 = 0.30\) - \(\lambda_2 = +1\) is an error: \(P(\Lambda_2 = +1 \mid Y = -1) = 1 - a_2 = 0.35\) - \(\lambda_3 = -1\) is correct: \(P(\Lambda_3 = -1 \mid Y = -1) = a_3 = 0.95\)

    \[ \mathbb{P}(\mathbf{\Lambda}_i \mid Y = -1) = 0.30 \times 0.35 \times 0.95 = 0.09975 \]

    Step 2: Apply Bayes' Rule With equal priors \(\mathbb{P}(Y = +1) = \mathbb{P}(Y = -1) = 0.5\):

    \[ \mathbb{P}(Y_i = +1 \mid \mathbf{\Lambda}_i) = \frac{0.02275}{0.02275 + 0.09975} = \frac{0.02275}{0.1225} \approx 0.1857 \quad (18.6\%) \]

    Step 3: Engineering Implications - Naive Majority Vote Failure: Naive voting counts votes uniformly (\(2\) against \(1\)), assigning hard label \(\hat{y} = +1\). This forces the neural network to learn a false positive pattern, corrupting the model's feature representation. - Generative Label Model Superiority: The generative model recognizes that \(\lambda_3\) is a high-precision expert rule (\(95\%\) accuracy), while \(\lambda_1\) and \(\lambda_2\) are noisy heuristics (\(65\% - 70\%\)). It correctly assigns a soft negative target \(\tilde{y}_i = 0.186\), allowing the noise-aware cross-entropy loss to guide the downstream classifier toward the correct negative decision boundary.

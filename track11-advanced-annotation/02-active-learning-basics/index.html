    🎯 Conceptual Overview & The Active Query Loop

    The foundational premise of Active Learning (AL) is that an intelligent machine learning algorithm can achieve higher predictive accuracy with significantly fewer labeled training instances if it is granted the autonomy to choose the data points from which it learns (Settles, 2012).

    In classical passive supervised learning, an annotation team annotates a randomly drawn independent and identically distributed (i.i.d.) sample \(\mathcal{S} \sim \mathcal{D}\) from the empirical data distribution. However, in enterprise real-world applications—such as autonomous driving perception, medical diagnostics, or high-throughput legal compliance—vast quantities of raw unlabelled observations are trivially cheap to acquire, whereas acquiring ground-truth labels requires expensive human domain specialists (Lewis & Gale, 1994). When passive random sampling is applied to massive data lakes, up to \(85\%\) of the human annotation budget is expended labeling redundant, highly confident, or easily classified instances that yield negligible parameter updates (Cohn et al., 1994).

    Active learning converts this static one-pass procedure into an iterative, closed-loop feedback system. A statistical model initially trained on a small seed set \(\mathcal{L}\) continuously evaluates an unlabeled pool \(\mathcal{U}\), computes an acquisition score \(\alpha(\mathbf{x})\) for each candidate instance, and dispatches queries to a human oracle only for those points that maximize expected statistical information gain (Gal et al., 2017).

    Structural Scenarios in Active Learning

    Active learning workflows are categorized into three primary structural scenarios depending on how candidate instances are accessed and presented to the query engine (Settles, 2012):

    1. Pool-Based Active Learning: The most prevalent enterprise operational setup. A large, static collection of unlabelled instances \(\mathcal{U} = \{\mathbf{x}_1, \dots, \mathbf{x}_U\}\) is persisted in cold or warm storage (e.g., S3 object lake or data warehouse). In each active learning round \(t\), the inference engine scores the entire pool \(\mathcal{U}\) using acquisition utility function \(\alpha(\mathbf{x})\), ranks the candidates, and queries the top-\(b\) ranked instances as a discrete batch for oracle labeling.

    2. Stream-Based Selective Sampling: Unlabelled observations arrive sequentially one-by-one from a live streaming bus (e.g., edge IoT sensors, autonomous vehicle LiDAR telemetry, continuous financial tick streams). The model must make an immediate, real-time decision whether to discard instance \(\mathbf{x}_t\) or dispatch it to the human oracle queue based on an acquisition threshold check:

    \[Q(\mathbf{x}_t) = \begin{cases} 1 & \text{if } \alpha(\mathbf{x}_t) \ge \tau \\ 0 & \text{if } \alpha(\mathbf{x}_t) < \tau \end{cases}\]

    Stream-based active learning eliminates the memory and compute overhead of maintaining and sorting billions of candidates simultaneously, making it suitable for memory-constrained edge hardware (Cohn et al., 1994).

    3. Membership Query Synthesis: Rather than sampling from an empirical distribution of real-world instances, the learning algorithm constructs entirely synthetic candidate coordinates \(\mathbf{x}^* \in \mathcal{X}\) from scratch within the feature space (e.g., using gradient ascent to maximize epistemic uncertainty) and requests an oracle label. While highly effective for synthetic physical simulations and robotics inverse kinematics, membership query synthesis notoriously fails when applied to human perceptual tasks (such as natural images or text), because synthetic coordinates generated in raw high-dimensional pixel or token space frequently correspond to unnatural static, unrecognizable chimera images, or ungrammatical gibberish that human oracles cannot interpret.

    📐 Formal Mathematical Foundations

    To formalize active learning acquisition dynamics, we establish four rigorous definitions governing posterior uncertainty metrics, version space disagreement, parameter gradient length bounds, and core-set geometric diversity guarantees.

    Definition 11.2.1: Uncertainty Sampling Acquisition Criteria (Least Confident, Margin, and Shannon Entropy)

    Let \(\mathcal{X} \subseteq \mathbb{R}^d\) denote the input feature space, and let \(\mathcal{Y} = \{1, 2, \dots, K\}\) denote a discrete label space with \(K \ge 2\) classes. Let \(f(\cdot; \theta): \mathcal{X} \to \Delta^{K-1}\) be a probabilistic classifier parameterized by weights \(\theta \in \Theta\), where \(\Delta^{K-1}\) is the probability simplex. For an unlabeled observation \(\mathbf{x} \in \mathcal{U}\), let \(P(y = k \mid \mathbf{x}; \theta)\) denote the model's posterior probability assigned to class \(k\).

    The three standard uncertainty sampling acquisition functions \(\alpha(\mathbf{x})\) are formally defined as follows:

    1. Normalized Least Confident (LC) Sampling: Evaluates the posterior probability of the single most probable predicted class. The normalized acquisition utility \(\alpha_{\text{LC}}(\mathbf{x}) \in [0, 1]\) is:

    \[\alpha_{\text{LC}}(\mathbf{x}) = \frac{K}{K - 1} \left(1 - \max_{k \in \mathcal{Y}} P(y = k \mid \mathbf{x}; \theta)\right)\]

    where the scalar scaling factor \(\frac{K}{K - 1}\) ensures that \(\alpha_{\text{LC}}(\mathbf{x}) = 0\) when the model is perfectly certain (\(\max_k P = 1.0\)), and \(\alpha_{\text{LC}}(\mathbf{x}) = 1\) under complete uniform uncertainty (\(P(y = k) = \frac{1}{K}, \forall k\)).

    2. Margin Sampling: Measures the probability differential between the two most likely class predictions. Let \(\hat{y}_1 = \arg\max_{k \in \mathcal{Y}} P(y = k \mid \mathbf{x}; \theta)\) and \(\hat{y}_2 = \arg\max_{k \in \mathcal{Y} \setminus \{\hat{y}_1\}} P(y = k \mid \mathbf{x}; \theta)\). The acquisition utility \(\alpha_{\text{Margin}}(\mathbf{x}) \in [0, 1]\) is:

    \[\alpha_{\text{Margin}}(\mathbf{x}) = 1 - \left(P(y = \hat{y}_1 \mid \mathbf{x}; \theta) - P(y = \hat{y}_2 \mid \mathbf{x}; \theta)\right)\]

    Instances with minimal margin between their top two candidate classes represent points situated in immediate proximity to the decision boundary separating those classes.

    3. Shannon Entropy Sampling: Measures the average information content and total distributional dispersion across all \(K\) classes:

    \[\alpha_{\text{Entropy}}(\mathbf{x}) = \mathcal{H}(Y \mid \mathbf{x}; \theta) = - \sum_{k=1}^K P(y = k \mid \mathbf{x}; \theta) \log_2 P(y = k \mid \mathbf{x}; \theta)\]

    Normalized Shannon entropy \(\widetilde{\mathcal{H}}(Y \mid \mathbf{x}; \theta) = \frac{\mathcal{H}(Y \mid \mathbf{x}; \theta)}{\log_2 K} \in [0, 1]\) maps the uncertainty score to the unit interval.

    [!IMPORTANT] Margin vs. Entropy Divergence: Margin sampling considers only the top two classes and is insensitive to the shape of the remaining tail distribution. In contrast, Shannon entropy accounts for all classes simultaneously. For binary classification (\(K = 2\)), Least Confident, Margin, and Shannon Entropy produce identical monotonic sample rankings; for multi-class problems (\(K \ge 3\)), their rankings diverge substantially.

    Definition 11.2.2: Version Space Disagreement & Query-by-Committee (QBC)

    Let \(\mathcal{H} = \{h: \mathcal{X} \to \mathcal{Y}\}\) denote the hypothesis space. Given a labeled dataset \(\mathcal{L} = \{(\mathbf{x}_i, y_i)\}_{i=1}^L\), the Version Space \(\mathcal{V}(\mathcal{L}) \subseteq \mathcal{H}\) is defined as the subset of all hypotheses that achieve zero empirical training error on \(\mathcal{L}\):

    \[\mathcal{V}(\mathcal{L}) = \left\{h \in \mathcal{H} : h(\mathbf{x}_i) = y_i, \quad \forall (\mathbf{x}_i, y_i) \in \mathcal{L}\right\}\]

    In Query-by-Committee (QBC) (Seung et al., 1992), an ensemble committee \(\mathcal{C} = \{\theta^{(1)}, \theta^{(2)}, \dots, \theta^{(C)}\}\) of \(C\) distinct models is sampled from the posterior distribution over the version space \(p(\theta \mid \mathcal{L})\).

    The committee disagreement for an unlabeled instance \(\mathbf{x} \in \mathcal{U}\) is measured via two primary metrics:

    1. Vote Entropy Disagreement: Let \(V(k, \mathbf{x}) = \sum_{c=1}^C \mathbb{I}\left(\arg\max_{j} P(y=j \mid \mathbf{x}; \theta^{(c)}) = k\right)\) be the number of committee members that predict class \(k\). The vote entropy is:

    \[\alpha_{\text{VE}}(\mathbf{x}) = - \sum_{k=1}^K \left(\frac{V(k, \mathbf{x})}{C}\right) \log_2 \left(\frac{V(k, \mathbf{x})}{C}\right)\]

    where \(\frac{0}{C} \log_2 \frac{0}{C} \equiv 0\).

    2. Consensus Kullback-Leibler (KL) Disagreement: Let \(P_{\text{cons}}(y = k \mid \mathbf{x}) = \frac{1}{C} \sum_{c=1}^C P(y = k \mid \mathbf{x}; \theta^{(c)})\) be the consensus distribution of the committee. The average relative entropy divergence is:

    \[D_{\text{KL}}^{\text{avg}}(\mathbf{x}) = \frac{1}{C} \sum_{c=1}^C D_{\text{KL}}\left(P\left(\cdot \mid \mathbf{x}; \theta^{(c)}\right) \,\Big\|\, P_{\text{cons}}(\cdot \mid \mathbf{x})\right) = \frac{1}{C} \sum_{c=1}^C \sum_{k=1}^K P\left(y = k \mid \mathbf{x}; \theta^{(c)}\right) \log_2 \left(\frac{P\left(y = k \mid \mathbf{x}; \theta^{(c)}\right)}{P_{\text{cons}}(y = k \mid \mathbf{x})}\right)\]

    3. Bayesian Active Learning by Disagreement (BALD): In deep Bayesian learning (Gal et al., 2017; Houlsby et al., 2011), committee members correspond to stochastic Monte Carlo Dropout forward passes \(\mathbf{w}^{(c)} \sim q(\mathbf{w})\). BALD computes the mutual information between the predicted label \(y\) and the model parameter distribution \(\mathbf{w}\):

    \[\mathcal{I}(y; \mathbf{w} \mid \mathbf{x}, \mathcal{L}) = \mathcal{H}\left[\mathbb{E}_{\mathbf{w} \sim p(\mathbf{w} \mid \mathcal{L})}[p(y \mid \mathbf{x}, \mathbf{w})]\right] - \mathbb{E}_{\mathbf{w} \sim p(\mathbf{w} \mid \mathcal{L})}\left[\mathcal{H}[p(y \mid \mathbf{x}, \mathbf{w})]\right]\]

    The first term represents total predictive entropy (epistemic + aleatoric), while the second term represents expected aleatoric noise. Their difference isolates pure epistemic uncertainty (model lack of knowledge), preventing the active learner from wasting queries on irreducible noisy boundary points.

    Definition 11.2.3: Expected Model Change & Gradient Length (EGL) Bounds

    Let \(\mathcal{L}_{\text{loss}}(f(\mathbf{x}; \theta), y)\) denote the differentiable supervised loss function (e.g., cross-entropy). Under stochastic gradient descent with learning rate \(\eta > 0\), receiving ground-truth label \(y\) for observation \(\mathbf{x}\) induces a first-order parameter update:

    \[\theta^{(t+1)} = \theta^{(t)} - \eta \nabla_\theta \mathcal{L}_{\text{loss}}\left(f(\mathbf{x}; \theta^{(t)}), y\right)\]

    Because the true label \(y\) is unknown prior to query dispatch, Expected Gradient Length (EGL) (Settles & Craven, 2008) computes the expected \(\ell_2\)-norm of the parameter gradient under the model's current posterior distribution:

    \[\alpha_{\text{EGL}}(\mathbf{x}) = \mathbb{E}_{y \sim P(Y \mid \mathbf{x}; \theta)}\left[\left\| \nabla_\theta \mathcal{L}_{\text{loss}}\left(f(\mathbf{x}; \theta), y\right) \right\|_2\right] = \sum_{k=1}^K P(y = k \mid \mathbf{x}; \theta) \left\| \nabla_\theta \mathcal{L}_{\text{loss}}\left(f(\mathbf{x}; \theta), k\right) \right\|_2\]

    The expected parameter displacement \(\Delta \theta = \|\theta^{(t+1)} - \theta^{(t)}\|_2\) satisfies the first-order Taylor bound:

    \[\mathbb{E}_y\left[\|\theta^{(t+1)} - \theta^{(t)}\|_2\right] = \eta \cdot \alpha_{\text{EGL}}(\mathbf{x}) + \mathcal{O}(\eta^2)\]

    Furthermore, EGL connects to the expected Fisher Information Matrix \(\mathcal{I}_{\text{Fisher}}(\theta) = \mathbb{E}_{\mathbf{x}, y}\left[\nabla_\theta \log P(y \mid \mathbf{x}; \theta) \nabla_\theta \log P(y \mid \mathbf{x}; \theta)^\top\right]\). Instances with maximal EGL provide maximal instantaneous contraction of the parameter covariance matrix under the Cramér-Rao lower bound:

    \[\operatorname{Cov}(\hat{\theta}) \ge \mathcal{I}_{\text{Fisher}}(\theta)^{-1}\]

    Definition 11.2.4: Diversity-Preserving Core-Set Active Selection & \(k\)-Center Bounds

    Pure uncertainty sampling suffers from batch redundancy: when querying a batch of \(b > 1\) instances simultaneously, the model selects \(b\) nearly identical instances that all reside in the same local uncertainty pocket, wasting \((b - 1)\) queries on redundant information (Sener & Savarese, 2018).

    Let \(\phi(\mathbf{x}) = \mathbf{z} \in \mathbb{R}^m\) denote a penultimate feature representation or embedding. Let \(\mathcal{Z}_{\mathcal{L}} = \{\phi(\mathbf{x}_i) : \mathbf{x}_i \in \mathcal{L}\}\) and \(\mathcal{Z}_{\mathcal{U}} = \{\phi(\mathbf{x}_j) : \mathbf{x}_j \in \mathcal{U}\}\).

    The Core-Set Active Selection Problem seeks a subset \(\mathbf{s} \subset \mathcal{U}\) of batch cardinality \(|\mathbf{s}| = b\) that minimizes the maximum Euclidean distance from any data point to its nearest labeled or selected center:

    \[\min_{\mathbf{s} \subset \mathcal{U}, |\mathbf{s}| = b} \max_{i \in \mathcal{U} \cup \mathcal{L}} \min_{j \in \mathbf{s} \cup \mathcal{L}} \|\mathbf{z}_i - \mathbf{z}_j\|_2\]

    This formulation is equivalent to the NP-hard \(k\)-Center facility location problem. The Greedy \(k\)-Center Algorithm initializes \(\mathbf{s} = \emptyset\) and iteratively picks:

    \[\mathbf{u}^* = \arg\max_{\mathbf{u} \in \mathcal{U} \setminus \mathbf{s}} \min_{\mathbf{v} \in \mathcal{L} \cup \mathbf{s}} \|\phi(\mathbf{u}) - \phi(\mathbf{v})\|_2, \quad \mathbf{s} \leftarrow \mathbf{s} \cup \{\mathbf{u}^*\}\]

    Theoretical Guarantee: The covering radius \(\delta_{\text{greedy}}(\mathbf{s})\) obtained by greedy \(k\)-center satisfies a strict 2-approximation factor bound (Sener & Savarese, 2018):

    \[\delta_{\text{greedy}}(\mathbf{s}) \le 2 \cdot \delta_{\text{OPT}}(\mathbf{s})\]

    where \(\delta_{\text{OPT}}(\mathbf{s})\) is the optimal covering radius achievable by any subset of size \(b\).

    To balance informative boundary querying with geometric spatial diversity, the Hybrid Acquisition Utility is parameterized by tradeoff coefficient \(\lambda \in [0, 1]\):

    \[\alpha_{\text{Hybrid}}(\mathbf{x}) = \lambda \cdot \widetilde{\alpha}_{\text{Uncertainty}}(\mathbf{x}) + (1 - \lambda) \cdot \widetilde{\Delta}_{\mathcal{L} \cup \mathbf{s}}(\mathbf{x})\]

    where \(\widetilde{\alpha}_{\text{Uncertainty}}(\mathbf{x}) \in [0, 1]\) is normalized margin or entropy, and \(\widetilde{\Delta}_{\mathcal{L} \cup \mathbf{s}}(\mathbf{x}) = \frac{\min_{\mathbf{v} \in \mathcal{L} \cup \mathbf{s}} \|\phi(\mathbf{x}) - \phi(\mathbf{v})\|_2}{\max_{\mathbf{u}} \min_{\mathbf{v}} \|\phi(\mathbf{u}) - \phi(\mathbf{v})\|_2} \in [0, 1]\).

    """Production Active Learning Strategy Pipeline with Pydantic V2 Validation."""

import numpy as np
from pydantic import BaseModel, Field, model_validator
from typing import List, Dict, Literal, Optional, Tuple
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification


class QueryBatchRequest(BaseModel):
    batch_size: int = Field(default=5, ge=1, description="Number of instances to select for labeling")
    strategy: Literal[
        'least_confident',
        'margin',
        'entropy',
        'qbc_vote_entropy',
        'qbc_kl_divergence',
        'bald',
        'core_set',
        'hybrid'
    ] = Field(default='margin', description="Acquisition utility strategy")
    hybrid_lambda: float = Field(default=0.5, ge=0.0, le=1.0, description="Tradeoff between uncertainty and diversity")


class QueryBatchResult(BaseModel):
    selected_indices: List[int]
    acquisition_scores: List[float]
    strategy_name: str
    candidate_pool_size: int
    min_pairwise_distance: float


class ActiveLearningEngine:
    """Production Active Learning Acquisition Engine for Uncertainty, QBC, BALD, and Core-Set."""

    @staticmethod
    def least_confident(probs: np.ndarray) -> np.ndarray:
        """Normalized Least Confident Sampling: alpha_LC(x) = |Y| / (|Y| - 1) * (1 - max_y P(y|x))."""
        k = probs.shape[1]
        if k <= 1:
            return np.zeros(probs.shape[0])
        max_p = np.max(probs, axis=1)
        scale = k / (k - 1)
        return scale * (1.0 - max_p)

    @staticmethod
    def margin_sampling(probs: np.ndarray) -> np.ndarray:
        """Margin Sampling: alpha_Margin(x) = 1.0 - (P(top1) - P(top2))."""
        sorted_probs = np.sort(probs, axis=1)[:, ::-1]
        top1 = sorted_probs[:, 0]
        top2 = sorted_probs[:, 1] if probs.shape[1] > 1 else np.zeros_like(top1)
        margin = top1 - top2
        return 1.0 - margin

    @staticmethod
    def shannon_entropy(probs: np.ndarray, eps: float = 1e-12) -> np.ndarray:
        """Shannon Entropy: H(Y|x) = - sum_y P(y|x) * log2(P(y|x))."""
        clipped = np.clip(probs, eps, 1.0)
        return -np.sum(clipped * np.log2(clipped), axis=1)

    @staticmethod
    def qbc_vote_entropy(committee_preds: np.ndarray, num_classes: int) -> np.ndarray:
        """QBC Vote Entropy across C committee members."""
        c, n = committee_preds.shape
        vote_entropies = np.zeros(n)
        for i in range(n):
            votes = np.bincount(committee_preds[:, i], minlength=num_classes)
            v_probs = votes / float(c)
            v_probs_c = v_probs[v_probs > 0]
            vote_entropies[i] = -np.sum(v_probs_c * np.log2(v_probs_c))
        return vote_entropies

    @staticmethod
    def qbc_kl_divergence(committee_probs: np.ndarray, eps: float = 1e-12) -> np.ndarray:
        """QBC Consensus Disagreement via average KL Divergence."""
        c, n, k = committee_probs.shape
        p_cons = np.mean(committee_probs, axis=0)
        p_cons = np.clip(p_cons, eps, 1.0)

        kl_divs = np.zeros(n)
        for member in range(c):
            p_m = np.clip(committee_probs[member], eps, 1.0)
            kl_m = np.sum(p_m * np.log2(p_m / p_cons), axis=1)
            kl_divs += kl_m
        return kl_divs / float(c)

    @staticmethod
    def bald_mutual_information(committee_probs: np.ndarray, eps: float = 1e-12) -> np.ndarray:
        """Bayesian Active Learning by Disagreement (BALD):
        I(y; w | x) = H[ E_w[p(y|x, w)] ] - E_w[ H[p(y|x, w)] ]
        """
        p_mean = np.mean(committee_probs, axis=0)
        p_mean = np.clip(p_mean, eps, 1.0)
        h_total = -np.sum(p_mean * np.log2(p_mean), axis=1)

        clipped_samples = np.clip(committee_probs, eps, 1.0)
        sample_entropies = -np.sum(clipped_samples * np.log2(clipped_samples), axis=2)
        expected_h = np.mean(sample_entropies, axis=0)

        return np.maximum(0.0, h_total - expected_h)

    @staticmethod
    def greedy_k_center(
        unlabeled_feats: np.ndarray,
        labeled_feats: np.ndarray,
        batch_size: int
    ) -> Tuple[List[int], float]:
        """Greedy k-Center Core-Set Active Selection."""
        n_unlabeled = len(unlabeled_feats)
        if n_unlabeled <= batch_size:
            return list(range(n_unlabeled)), 0.0

        dists = np.linalg.norm(unlabeled_feats[:, np.newaxis, :] - labeled_feats[np.newaxis, :, :], axis=2)
        min_dists = np.min(dists, axis=1)

        selected_indices: List[int] = []
        selected_mask = np.zeros(n_unlabeled, dtype=bool)

        for _ in range(batch_size):
            candidate_dists = np.where(selected_mask, -1.0, min_dists)
            best_idx = int(np.argmax(candidate_dists))
            selected_indices.append(best_idx)
            selected_mask[best_idx] = True

            new_point = unlabeled_feats[best_idx:best_idx + 1, :]
            new_dists = np.linalg.norm(unlabeled_feats - new_point, axis=1)
            min_dists = np.minimum(min_dists, new_dists)

        if len(selected_indices) > 1:
            sel_feats = unlabeled_feats[selected_indices]
            p_dists = np.linalg.norm(sel_feats[:, np.newaxis, :] - sel_feats[np.newaxis, :, :], axis=2)
            np.fill_diagonal(p_dists, np.inf)
            min_pairwise = float(np.min(p_dists))
        else:
            min_pairwise = float(min_dists[selected_indices[0]])

        return selected_indices, min_pairwise

    @classmethod
    def select_batch(
        cls,
        req: QueryBatchRequest,
        unlabeled_feats: np.ndarray,
        labeled_feats: np.ndarray,
        unlabeled_probs: Optional[np.ndarray] = None,
        committee_probs: Optional[np.ndarray] = None,
        committee_preds: Optional[np.ndarray] = None,
    ) -> QueryBatchResult:
        n_unlabeled = len(unlabeled_feats)

        if req.strategy == 'least_confident':
            assert unlabeled_probs is not None
            scores = cls.least_confident(unlabeled_probs)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'margin':
            assert unlabeled_probs is not None
            scores = cls.margin_sampling(unlabeled_probs)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'entropy':
            assert unlabeled_probs is not None
            scores = cls.shannon_entropy(unlabeled_probs)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'qbc_vote_entropy':
            assert committee_preds is not None
            num_classes = int(np.max(committee_preds)) + 1
            scores = cls.qbc_vote_entropy(committee_preds, num_classes=num_classes)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'qbc_kl_divergence':
            assert committee_probs is not None
            scores = cls.qbc_kl_divergence(committee_probs)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'bald':
            assert committee_probs is not None
            scores = cls.bald_mutual_information(committee_probs)
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        elif req.strategy == 'core_set':
            top_indices, min_p = cls.greedy_k_center(unlabeled_feats, labeled_feats, req.batch_size)
            scores = np.zeros(n_unlabeled)
            for rank, idx in enumerate(top_indices):
                scores[idx] = float(req.batch_size - rank)
        elif req.strategy == 'hybrid':
            assert unlabeled_probs is not None
            unc = cls.margin_sampling(unlabeled_probs)
            unc_norm = (unc - np.min(unc)) / (np.ptp(unc) + 1e-12)

            dists = np.linalg.norm(unlabeled_feats[:, np.newaxis, :] - labeled_feats[np.newaxis, :, :], axis=2)
            div = np.min(dists, axis=1)
            div_norm = (div - np.min(div)) / (np.ptp(div) + 1e-12)

            scores = req.hybrid_lambda * unc_norm + (1.0 - req.hybrid_lambda) * div_norm
            top_indices = np.argsort(scores)[::-1][:req.batch_size].tolist()
        else:
            raise ValueError(f"Unknown strategy {req.strategy}")

        sel_pts = unlabeled_feats[top_indices]
        if len(sel_pts) > 1:
            p_dists = np.linalg.norm(sel_pts[:, np.newaxis, :] - sel_pts[np.newaxis, :, :], axis=2)
            np.fill_diagonal(p_dists, np.inf)
            min_pair = float(np.min(p_dists))
        else:
            min_pair = 0.0

        return QueryBatchResult(
            selected_indices=top_indices,
            acquisition_scores=[float(scores[i]) for i in top_indices],
            strategy_name=req.strategy,
            candidate_pool_size=n_unlabeled,
            min_pairwise_distance=round(min_pair, 4)
        )

    Self-Assessment 2: Mathematical Proof of BALD Aleatoric Noise Rejection

    Let candidate instance \(\mathbf{x}_{\text{noise}}\) be a point corrupted by pure aleatoric noise (e.g., an unresolvable coin flip or blurred sensor recording where ground-truth label \(y \in \{0, 1\}\) is fundamentally non-deterministic with \(P(y=1) = 0.50\)).

    Suppose every committee member \(\mathbf{w}^{(c)} \sim p(\mathbf{w} \mid \mathcal{L})\) in an active learning ensemble recognizes this noise and outputs identical posterior predictions:

    \[p(y = 1 \mid \mathbf{x}_{\text{noise}}, \mathbf{w}^{(c)}) = 0.50, \quad \forall c \in \{1, \dots, C\}\]

    1. Compute the Shannon Entropy \(\mathcal{H}\left[\mathbb{E}_{\mathbf{w}}[p(y \mid \mathbf{x}_{\text{noise}}, \mathbf{w})]\right]\).

    2. Compute the expected sample entropy \(\mathbb{E}_{\mathbf{w}}\left[\mathcal{H}[p(y \mid \mathbf{x}_{\text{noise}}, \mathbf{w})]\right]\).

    3. Deduce the BALD mutual information score \(\mathcal{I}(y; \mathbf{w} \mid \mathbf{x}_{\text{noise}}, \mathcal{L})\). What is the engineering consequence for active learning?

    Reveal Detailed Solution & Step-by-Step Derivation

    1. Total Predictive Entropy: The expected posterior distribution across all committee passes is:

    \[\bar{p}(y = 1 \mid \mathbf{x}_{\text{noise}}) = \frac{1}{C} \sum_{c=1}^C 0.50 = 0.50, \quad \bar{p}(y = 0 \mid \mathbf{x}_{\text{noise}}) = 0.50\]

    The entropy of this mean distribution is:

    \[\mathcal{H}\left[\mathbb{E}_{\mathbf{w}}[p(y \mid \mathbf{x}_{\text{noise}}, \mathbf{w})]\right] = - \left(0.50 \log_2 0.50 + 0.50 \log_2 0.50\right) = 1.00\text{ bit}\]

    2. Expected Sample Entropy: For each individual committee member \(c\), the predicted entropy is:

    \[\mathcal{H}[p(y \mid \mathbf{x}_{\text{noise}}, \mathbf{w}^{(c)})] = - \left(0.50 \log_2 0.50 + 0.50 \log_2 0.50\right) = 1.00\text{ bit}\]

    Taking the expectation across the committee:

    \[\mathbb{E}_{\mathbf{w}}\left[\mathcal{H}[p(y \mid \mathbf{x}_{\text{noise}}, \mathbf{w})]\right] = \frac{1}{C} \sum_{c=1}^C 1.00 = 1.00\text{ bit}\]

    3. BALD Mutual Information Score: Subtracting the expected sample entropy from the total predictive entropy yields:

    \[\mathcal{I}(y; \mathbf{w} \mid \mathbf{x}_{\text{noise}}, \mathcal{L}) = \mathcal{H}\left[\mathbb{E}_{\mathbf{w}}[p]\right] - \mathbb{E}_{\mathbf{w}}[\mathcal{H}[p]] = 1.00 - 1.00 = \mathbf{0.00\text{ bits}}\]

    Engineering Consequence: Under standard single-model Shannon Entropy sampling, instance \(\mathbf{x}_{\text{noise}}\) achieves the maximum possible score (\(1.00\text{ bit}\)) and is aggressively queried by the active learner. However, because the instance contains pure irreducible aleatoric noise, human labels provide zero information to update model weights \(\mathbf{w}\).

    In sharp contrast, BALD computes an acquisition score of exactly \(0.00\text{ bits}\). Because all committee members agree on the predictive distribution (even though the distribution is maximally uncertain), there is zero parameter uncertainty (epistemic disagreement). BALD correctly filters out the noisy trap, preserving human annotation budget for genuine epistemic edge cases.

    Once records are clean, deduplicated, and consistent, raw columns remain poorly conditioned for machine learning algorithms. Numerical features spanning disparate orders of magnitude warp loss surface curvature and distort Euclidean distance metrics, while discrete categorical strings cannot be directly consumed by matrix multiplication or kernel methods [MicciBarreca2001, Weinberger2009].

    Rigorous preprocessing transforms feature spaces to stabilize Hessian condition numbers \(\kappa(\mathbf{H})\), resist outlier scaling collapse [Hampel1974, Rousseeuw1999], and encode high-cardinality categorical dimensions without incurring target leakage or matrix singularity.

    2. Numerical Scaling & Optimization Geometry

    1. The Hessian Condition Number Theorem

    In gradient-based optimization (Logistic Regression, SVMs, Neural Networks), the optimization convergence rate around optimal weights \(\mathbf{w}^*\) is dictated by the eigenvalues of the Hessian curvature matrix \(\mathbf{H} = \nabla^2 \mathcal{L}(\mathbf{w})\):

    \[ \kappa(\mathbf{H}) = \frac{\lambda_{\max}(\mathbf{H})}{\lambda_{\min}(\mathbf{H})} \]

    If feature \(X_1 \in [0, 1]\) and \(X_2 \in [0, 10^6]\), the Hessian eigenvalues scale proportionally (\(\kappa(\mathbf{H}) \approx 10^{12}\)). Level curves deform into hyper-elongated ellipses, forcing gradient descent to zig-zag across the steep walls of \(X_2\) while stagnating along \(X_1\). Scaling features to unit variance bounds \(\kappa(\mathbf{H}) \to 1\), turning elongated troughs into spherical bowls for rapid \(\mathcal{O}(\ln(1/\epsilon))\) convergence.

    2. Comparative Scaling Mathematics

    Scaler Mathematical Formulation Breakdown Point (\(\epsilon^*\)) Optimal Application Primary Failure Mode
    StandardScaler (\(Z\)-Score) \(x_i' = \frac{x_i - \mu}{\sigma}\) \(0\%\) (\(\frac{1}{n}\)) Symmetric near-Gaussian features A single extreme outlier inflates \(\sigma \to \infty\), squashing inliers to zero
    MinMaxScaler \(x_i' = \frac{x_i - \min(\mathbf{x})}{\max(\mathbf{x}) - \min(\mathbf{x})}\) \(0\%\) (\(\frac{1}{n}\)) Bounded images (\([0, 255]\)), neural activations Sensitive to single outlier clipping; test values can escape \([0, 1]\)
    RobustScaler (Order Stats) \(x_i' = \frac{x_i - Q_2(\mathbf{x})}{Q_3(\mathbf{x}) - Q_1(\mathbf{x})}\) \(25\%\) (IQR) Financial amounts, skewed telemetry, outlier-prone streams Preserves extreme scale asymmetry between skewed tails
    Yeo-Johnson Power Transform \(\psi(\lambda, x) = \frac{(x+1)^\lambda - 1}{\lambda}\) (\(x \ge 0\)) N/A (Parametric MLE) Extreme log-normal / exponential skew (handles \(x \le 0\)) Parametric estimation can fail on multimodal discrete spikes

    3. Categorical Encoding: Linear Algebra & Information Bounds

    Let categorical random variable \(C \in \{c_1, c_2, \dots, c_K\}\) have cardinality \(|C| = K\).

    1. One-Hot Encoding & The Dummy Variable Trap

    One-hot encoding maps each discrete symbol \(c_k\) onto an orthogonal basis vector \(\mathbf{e}_k \in \mathbb{R}^K\). However, adding an intercept bias column \(\mathbf{1}\) to a linear regression matrix yields exact linear dependence across all \(K\) dummy indicators:

    \[ \sum_{k=1}^K \phi_k(c) = \mathbf{1} \implies \operatorname{rank}\left( [\mathbf{1}, \mathbf{\Phi}_{\text{OHE}}] \right) < K + 1 \implies \det(\mathbf{X}^\top \mathbf{X}) = 0 \]

    Because \(\mathbf{X}^\top \mathbf{X}\) becomes strictly singular, unregularized Ordinary Least Squares normal equations \((\mathbf{X}^\top \mathbf{X})^{-1}\mathbf{X}^\top \mathbf{y}\) have infinite solutions. Dropping one reference column (OneHotEncoder(drop="first")) restores full matrix rank (\(K-1\) indicators + intercept).

    2. High-Cardinality Encoding: Empirical Bayes Shrinkage

    When \(K \gg 100\) (e.g., \(40{,}000\) postal ZIP codes), One-Hot matrices bloat memory consumption and fracture decision tree split capacity. Target Encoding compresses all \(K\) categories into a single informative float estimating \(\mathbb{E}[Y \mid C = c]\).

    To eliminate severe overfitting on low-frequency categories (\(n_c = 1 \implies \bar{y}_c \in \{0, 1\}\)), Micci-Barreca Empirical Bayes Shrinkage [MicciBarreca2001] blends category mean \(\bar{y}_c\) toward the global training prior \(\bar{y}\):

    \[ S_c = \lambda(n_c) \bar{y}_c + \left(1 - \lambda(n_c)\right) \bar{y}, \qquad \text{where } \lambda(n_c) = \frac{1}{1 + \exp\left(-\frac{n_c - k}{f}\right)} \]

    Or via the analytical \(m\)-Estimate Smoothing Formula with prior pseudo-count \(m > 0\):

    \[ S_c = \frac{n_c \bar{y}_c + m \bar{y}}{n_c + m} \]

    To guarantee zero target leakage during training, category encodings must be computed strictly Out-of-Fold (K-Fold) or via Ordered Target Statistics (CatBoost formulation over random row permutation \(\sigma\)):

    \[ S_i = \frac{\sum_{j: \sigma(j) < \sigma(i)} \mathbb{I}(x_j = x_i) y_j + a \cdot \bar{y}}{\sum_{j: \sigma(j) < \sigma(i)} \mathbb{I}(x_j = x_i) + a} \]

    3. Signed Feature Hashing (The Hashing Trick)

    For ultra-high-cardinality text/ID streams (\(K > 10^7\)), Weinberger Feature Hashing [Weinberger2009] maps category tokens into a compact fixed-size vector \(\mathbb{R}^B\) via hash index \(h: \mathcal{S} \to \{0, \dots, B-1\}\) and binary Rademacher sign hash \(\xi: \mathcal{S} \to \{-1, +1\}\):

    \[ \phi_j^{(h, \xi)}(x) = \sum_{i: h(i) = j} \xi(i) x_i \]

    Including the random sign flip \(\xi(i) \in \{-1, +1\}\) ensures that hash collisions cancel out in expectation, guaranteeing exact unbiasedness of vector inner products:

    \[ \mathbb{E}_{h, \xi}\left[ \langle \phi^{(h, \xi)}(x), \phi^{(h, \xi)}(x') \rangle \right] = \langle x, x' \rangle \]

    Industrial Best Practice: Out-of-Fold Empirical Bayes Target Encoding

    Never call .fit_transform() on the entire training table when computing target means. Wrap target encoding inside \(K\)-fold cross-validation splits during training so each observation's encoded coordinate never observes its own true target label \(y_i\).

    Common Pitfall / Anti-Pattern: Applying StandardScaler or MinMaxScaler on Unwinsorized Skewed Data

    A single fraudulent transaction of \(\$2{,}000{,}000\) in a stream centered at \(\$50\) destroys MinMaxScaler (crushing 99.9% of legitimate purchases inside \([0, 0.0001]\)) and severely degrades StandardScaler. Always apply RobustScaler or log transforms (np.log1p) for heavy-tailed distributions.

    6. Production-Grade Python Verification Engine

    The following Python module uses Pydantic V2 to test the Dummy Variable Trap Matrix Singularity (det == 0), Outlier Compression Comparison (MinMaxScaler vs. RobustScaler), Out-of-Fold Empirical Bayes Target Encoding, and unbiased Signed Feature Hashing.

    """
production_scaling_and_encoding.py
Pydantic V2 verified engine for Scaling Breakdown, OHE Singularity, and Leak-Free Target Encoding.
"""

from typing import List, Dict
import math
import hashlib
import numpy as np
import pandas as pd
from pydantic import BaseModel, Field
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.model_selection import KFold
from sklearn.preprocessing import OneHotEncoder, MinMaxScaler, RobustScaler


class PreprocessingVerificationReport(BaseModel):
    """Pydantic V2 audit schema confirming singularity avoidance, scaling stability, and leak-free encoding."""
    full_ohe_matrix_determinant: float
    dropped_ohe_matrix_determinant: float
    minmax_inlier_std_after_outlier: float
    robust_inlier_std_after_outlier: float
    frequency_1_target_encoding_leak_prevented: bool
    feature_hashing_inner_product_rel_error: float


class LeakFreeTargetEncoder(BaseEstimator, TransformerMixin):
    """Out-of-Fold Empirical Bayes m-Estimate Target Encoder preventing training set leakage."""

    def __init__(self, m: float = 15.0, cv: int = 5, random_state: int = 42):
        self.m = m
        self.cv = cv
        self.random_state = random_state
        self.global_mean_ = 0.0
        self.mapping_: Dict[str, Dict[str, float]] = {}

    def fit(self, X: pd.DataFrame, y: pd.Series):
        X_df = pd.DataFrame(X).copy()
        y_ser = pd.Series(y).copy()
        self.global_mean_ = float(y_ser.mean())
        for col in X_df.columns:
            stats = y_ser.groupby(X_df[col]).agg(["count", "mean"])
            smoothed = (stats["count"] * stats["mean"] + self.m * self.global_mean_) / (stats["count"] + self.m)
            self.mapping_[col] = smoothed.to_dict()
        return self

    def fit_transform(self, X: pd.DataFrame, y: pd.Series) -> pd.DataFrame:
        X_df = pd.DataFrame(X).copy().reset_index(drop=True)
        y_ser = pd.Series(y).copy().reset_index(drop=True)
        self.fit(X_df, y_ser)

        X_out = pd.DataFrame(index=X_df.index, columns=X_df.columns, dtype=float)
        kf = KFold(n_splits=self.cv, shuffle=True, random_state=self.random_state)

        for train_idx, val_idx in kf.split(X_df):
            X_tr, y_tr = X_df.iloc[train_idx], y_ser.iloc[train_idx]
            X_val = X_df.iloc[val_idx]
            fold_prior = float(y_tr.mean())
            for col in X_df.columns:
                stats = y_tr.groupby(X_tr[col]).agg(["count", "mean"])
                fold_map = ((stats["count"] * stats["mean"] + self.m * fold_prior) / (stats["count"] + self.m)).to_dict()
                X_out.loc[val_idx, col] = X_val[col].map(fold_map).fillna(fold_prior)
        return X_out.astype(float)

    def transform(self, X: pd.DataFrame) -> pd.DataFrame:
        X_df = pd.DataFrame(X).copy()
        X_out = pd.DataFrame(index=X_df.index, columns=X_df.columns, dtype=float)
        for col in X_df.columns:
            col_map = self.mapping_.get(col, {})
            X_out[col] = X_df[col].map(col_map).fillna(self.global_mean_)
        return X_out.astype(float)


def signed_feature_hash(tokens: List[str], dim: int = 128) -> np.ndarray:
    """Weinberger et al. signed feature hashing mapping strings to R^dim unbiased in inner products."""
    vec = np.zeros(dim, dtype=float)
    for tok in tokens:
        digest = hashlib.blake2b(tok.encode("utf-8"), digest_size=8).digest()
        h_val = int.from_bytes(digest[:4], "little") % dim
        sign = 1.0 if (int.from_bytes(digest[4:], "little") % 2 == 0) else -1.0
        vec[h_val] += sign
    return vec


def test_scaling_and_encoding_assertions():
    np.random.seed(42)

    # 1. Dummy Variable Trap Singularity Proof
    cats = np.array([["A"], ["B"], ["C"], ["A"], ["B"]])
    ohe_full = OneHotEncoder(sparse_output=False).fit_transform(cats)
    X_full = np.hstack([np.ones((len(cats), 1)), ohe_full])
    det_full = float(np.linalg.det(X_full.T @ X_full))

    ohe_drop = OneHotEncoder(drop="first", sparse_output=False).fit_transform(cats)
    X_drop = np.hstack([np.ones((len(cats), 1)), ohe_drop])
    det_drop = float(np.linalg.det(X_drop.T @ X_drop))

    assert abs(det_full) < 1e-10, "Full OHE with intercept must produce singular matrix!"
    assert det_drop > 1.0, "Dropped OHE must yield invertible non-singular matrix!"

    # 2. Outlier Compression Check: MinMaxScaler vs RobustScaler
    inliers = np.random.normal(50.0, 5.0, size=(200, 1))
    corrupted = np.vstack([inliers, [[10_000.0]]])
    std_minmax = float(np.std(MinMaxScaler().fit_transform(corrupted)[:200]))
    std_robust = float(np.std(RobustScaler().fit_transform(corrupted)[:200]))

    assert std_minmax < 0.01, "MinMaxScaler must exhibit catastrophic inlier compression!"
    assert std_robust > 0.50, "RobustScaler must preserve nominal variance!"

    # 3. Leak-Free Out-of-Fold Target Encoding Check
    df_cat = pd.DataFrame({"zip": ["Z_Common"] * 99 + ["Z_Rare_Freq1"]})
    y_target = pd.Series([0.0] * 80 + [1.0] * 19 + [1.0])
    encoder = LeakFreeTargetEncoder(m=15.0, cv=5)
    encoded_oof = encoder.fit_transform(df_cat, y_target)
    # Frequency-1 rare category falls back strictly to its fold prior (~0.19) rather than leaking 1.0!
    rare_encoded = float(encoded_oof.loc[99, "zip"])
    assert rare_encoded < 0.30, f"Target encoding leaked rare label! Got {rare_encoded}"

    # 4. Signed Feature Hashing Inner Product Test
    tokens_a = [f"tok_{i}" for i in range(20)]
    tokens_b = [f"tok_{i}" for i in range(10, 30)]  # Overlap of 10 tokens
    true_dot = 10.0
    v_a = signed_feature_hash(tokens_a, dim=512)
    v_b = signed_feature_hash(tokens_b, dim=512)
    approx_dot = float(np.dot(v_a, v_b))
    rel_err = abs(approx_dot - true_dot) / true_dot
    assert rel_err < 0.40

    report = PreprocessingVerificationReport(
        full_ohe_matrix_determinant=det_full,
        dropped_ohe_matrix_determinant=det_drop,
        minmax_inlier_std_after_outlier=round(std_minmax, 6),
        robust_inlier_std_after_outlier=round(std_robust, 4),
        frequency_1_target_encoding_leak_prevented=(rare_encoded < 0.30),
        feature_hashing_inner_product_rel_error=round(rel_err, 4),
    )

    print("=== Production Scaling & Encoding Verification ===")

    7. Key Engineering Takeaways

    1. Condition Numbers Govern Gradient Speed: Standardizing features to comparable scales lowers the Hessian condition number \(\kappa(\mathbf{H}) \to 1\), eliminating gradient descent oscillations.
    2. Median/IQR Defeat Extreme Outliers: Unlike MinMaxScaler and StandardScaler (\(0\%\) breakdown), RobustScaler preserves nominal inlier geometry cleanly when extreme outliers enter data streams.
    3. Avoid Singularity & Leakage in Encoding: Always specify drop="first" when feeding One-Hot indicators into unregularized linear solvers, and always execute Empirical Bayes Target Encoding inside \(K\)-fold cross-validation splits.
    4. Hashing Scales Unbounded Taxonomies: When category dictionaries exceed millions of tokens, Weinberger's signed hashing embeds infinite keys into fixed \(\mathcal{O}(B)\) memory with zero dot-product expectation bias.

    8. Scenario-Based Diagnostic Micro-Checks

    Micro-Check 1: RobustScaler vs. StandardScaler in Presence of Extreme Outliers

    A fraud telemetry dataset contains transaction amounts averaging \(\$50\) (\(\text{IQR} = \$35\)), alongside a single corrupted entry logging \(\$5{,}000{,}000\). Explain mathematically why MinMaxScaler and StandardScaler crush nominal variation while RobustScaler stays unaffected.

    Reveal Detailed Solution

    Both MinMaxScaler and StandardScaler exhibit a \(0\%\) breakdown point; RobustScaler resists up to \(25\%\) extreme tail contamination.

    1. MinMaxScaler divides by \(\max(\mathbf{x}) - \min(\mathbf{x}) = 5{,}000{,}000\), mapping every transaction under \(\$100\) into \([0.00000, 0.00002]\), effectively turning normal transaction features into an indistinguishable flat zero.
    2. StandardScaler relies on empirical standard deviation \(\sigma\), which swells with \((5{,}000{,}000)^2\), flattening inliers identically.
    3. RobustScaler scales strictly using the median \(Q_2\) and Interquartile Range (\(Q_3 - Q_1 = \$35\)). Neither order statistic changes when a single observation jumps to infinity, preserving full nominal dispersion.
    Micro-Check 2: Out-of-Fold vs. In-Sample Target Encoding Leakage

    A data engineer replaces "ZIP_Code" with simple in-sample mean fraud rate groupby("ZIP_Code")["IsFraud"].mean() across the entire training dataset before splitting cross-validation folds. Why does training \(R^2\)/AUC jump to \(0.99\) while test set generalization collapses?

    Reveal Detailed Solution

    Rare or unique categories memorize their own exact binary label, embedding the target variable directly into the input matrix.

    If a single house or rare ZIP code appears once in training (\(n_c = 1\)) and defaulted (\(y=1\)), naive target encoding maps that ZIP directly to 1.000, whereas single non-defaults map to 0.000. Decision trees instantly split at ZIP_Encoded > 0.5, achieving near-zero training error while failing completely on unseen test categories. Out-of-Fold (\(K\)-fold) Empirical Bayes encoding enforces two protections: 1. Fold isolation guarantees row \(i\) never participates in computing its own encoded feature. 2. Shrinkage parameter \(m\) pulls sparse observations back toward the global mean \(\bar{y}\).

    Micro-Check 3: Linear Algebra of the Dummy Variable Trap

    Given a regression design matrix \(\mathbf{X}\) containing an intercept bias column \(\mathbf{1}\) alongside all \(K = 3\) full One-Hot columns (["Red", "Green", "Blue"]), prove mathematically why unregularized Ordinary Least Squares \(\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1}\mathbf{X}^\top \mathbf{y}\) cannot yield a unique solution.

    Reveal Detailed Solution

    The columns of \(\mathbf{X}\) are linearly dependent, forcing \(\det(\mathbf{X}^\top \mathbf{X}) = 0\).

    Because every sample must belong to exactly one mutually exclusive color: $\(\phi_{\text{Red}}(x_i) + \phi_{\text{Green}}(x_i) + \phi_{\text{Blue}}(x_i) = 1 = \mathbf{X}_{i, \text{intercept}}\)$ This implies there exists a non-zero null-space vector \(\mathbf{v} = [-1, 1, 1, 1]^\top \ne \mathbf{0}\) such that \(\mathbf{X}\mathbf{v} = \mathbf{0}\). Consequently, \(\mathbf{X}^\top \mathbf{X}\) is rank-deficient (\(\det(\mathbf{X}^\top \mathbf{X}) = 0\)) and mathematically non-invertible. Dropping "Red" (drop="first") destroys the linear dependency and restores uniqueness.

    Micro-Check 4: Why Signed Feature Hashing Removes Collision Bias

    Why does Weinberger's Hashing Trick introduce a secondary Rademacher sign hash \(\xi(i) \in \{-1, +1\}\) alongside index hash \(h(i) \in \{0, \dots, B-1\}\)?

    Reveal Detailed Solution

    Without the random sign \(\xi\), hash collisions systematically inflate vector magnitudes and dot products upward (positive bias).

    If two distinct sparse indicators map to the same bucket \(j = h(a) = h(b)\), an unsigned frequency hash sums \(x_a + x_b\), making \(\langle \phi(x), \phi(x') \rangle\) strictly overestimate true similarity whenever collisions occur. By multiplying values by zero-mean random signs \(\mathbb{E}[\xi(a)\xi(b)] = \mathbb{I}(a = b)\), colliding pairs \(a \ne b\) produce \(+1\) half the time and \(-1\) half the time: $\(\mathbb{E}\left[ \phi_j(x) \phi_j(x') \right] = \sum_{a \in \text{bucket } j} x_a x'_a + \underbrace{\sum_{a \ne b} x_a x'_b \mathbb{E}[\xi(a)\xi(b)]}_{= 0}\)$ The expected inner product becomes exact and unbiased regardless of bucket count \(B\).

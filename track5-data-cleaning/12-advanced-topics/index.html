    🎯 Conceptual Overview & Frontier Architectures

    Static batch preprocessing on fixed CSV datasets cannot support modern real-time streaming architectures, high-dimensional non-linear missingness, or pervasive human label corruption. Advanced data preparation bridges into deep generative imputation, online streaming martingales (Montiel et al., 2021), and confident learning label auditing (Yoon et al., 2018; Northcutt et al., 2021; Krishnan et al., 2016; Schelter et al., 2018).

    1. Generative Adversarial Imputation Networks (GAIN)

    Classical conditional mean or chained MICE models fail when missingness patterns involve complex high-dimensional non-linear interactions. GAIN (Yoon et al., 2018) adapts the generative adversarial framework to impute missing components conditioned on observed elements:

    Let \(\mathbf{X} = (X_1, \dots, X_d)\) be a random vector, and \(\mathbf{M} = (M_1, \dots, M_d) \in \{0, 1\}^d\) be the missingness mask indicator (\(M_j = 1\) if observed, \(0\) if missing). Let \(\tilde{\mathbf{X}} = \mathbf{X} \odot \mathbf{M} + \mathbf{Z} \odot (1 - \mathbf{M})\) where \(\mathbf{Z} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})\) is synthetic noise.

    1. Generator (\(G\)): Takes \((\tilde{\mathbf{X}}, \mathbf{M})\) and outputs imputed vector \(\bar{\mathbf{X}} = G(\tilde{\mathbf{X}}, \mathbf{M})\). The final completed vector is:
    \[ \hat{\mathbf{X}} = \mathbf{X} \odot \mathbf{M} + \bar{\mathbf{X}} \odot (1 - \mathbf{M}) \]
    1. Discriminator (\(D\)): Unlike standard GANs which classify real vs. synthetic instances, the GAIN discriminator predicts the component-wise mask vector \(\mathbf{M}\) given \(\hat{\mathbf{X}}\) and a hint vector \(\mathbf{H} \in \{0, 0.5, 1\}^d\):
    \[ \min_G \max_D V(D, G) = \mathbb{E}_{\tilde{\mathbf{X}}, \mathbf{M}, \mathbf{H}} \left[ \mathbf{M}^\top \log D(\hat{\mathbf{X}}, \mathbf{H}) + (1 - \mathbf{M})^\top \log (1 - D(\hat{\mathbf{X}}, \mathbf{H})) \right] \]

    The hint vector \(\mathbf{H}\) reveals partial information about \(\mathbf{M}\) to prevent the discriminator from trivial collapse, guaranteeing that \(G\) learns the true underlying conditional distribution \(P(\mathbf{X}_{\text{mis}} \mid \mathbf{X}_{\text{obs}})\).

    2. Online Streaming Preprocessing: Welford's Algorithm

    In ultra-low-latency event streaming (e.g., IoT sensors, financial tick data), recalculating global moments \(\mu, \sigma\) across historical buffers is computationally intractable (\(\mathcal{O}(n)\) time and unbounded \(\mathcal{O}(n)\) memory).

    Welford's One-Pass Algorithm (Welford, 1962) computes exact streaming sample mean and variance in \(\mathcal{O}(1)\) time and \(\mathcal{O}(1)\) memory:

    \[ \mu_k = \mu_{k-1} + \frac{x_k - \mu_{k-1}}{k} \]
    \[ M_{2, k} = M_{2, k-1} + (x_k - \mu_{k-1})(x_k - \mu_k) \]

    where sample variance after \(k\) stream observations is:

    \[ s_k^2 = \frac{M_{2, k}}{k - 1} \]

    For non-stationary, drifting data streams, the Exponentially Weighted Moving Average (EWMA) applies decay parameter \(\alpha \in (0, 1)\):

    \[ \mu_t = (1 - \alpha) \mu_{t-1} + \alpha x_t \]
    \[ \sigma_t^2 = (1 - \alpha) \sigma_{t-1}^2 + \alpha (x_t - \mu_t)^2 \]

    3. Confident Learning for Label Error Detection

    Labels in real-world training sets are contaminated by human fatigue, annotator ambiguity, and synthetic pipeline mistakes. Confident Learning (Northcutt et al., 2021) directly models the joint distribution \(\hat{Q}_{\tilde{y}, y^*}\) of observed noisy labels \(\tilde{y}\) and latent ground truth labels \(y^*\).

    1. Out-of-Fold Probability Estimation: Estimate predicted probabilities \(\hat{p}_i = \hat{P}(\tilde{y} = k \mid \mathbf{x}_i)\) via cross-validation.
    2. Class-Specific Confidence Thresholds: For each class \(j \in \{1, \dots, C\}\):
    \[ t_j = \frac{1}{|X_{\tilde{y}=j}|} \sum_{\mathbf{x} \in X_{\tilde{y}=j}} \hat{P}(\tilde{y} = j \mid \mathbf{x}) \]
    1. Confident Joint Matrix (\(\mathbf{C}_{\tilde{y}, y^*}\)): An instance \(\mathbf{x}\) labeled \(\tilde{y} = i\) is assigned to latent class \(y^* = j\) if:
    \[ j = \arg\max_{k \in \{1, \dots, C\}} \hat{P}(\tilde{y} = k \mid \mathbf{x}) \quad \text{and} \quad \hat{P}(\tilde{y} = j \mid \mathbf{x}) \ge t_j \]

    Instances where \(\tilde{y} \neq y^*\) represent certified label errors and are automatically pruned from the training corpus.

    Industrial Best Practice: ActiveClean Gradient-Informed Sample Prioritization

    When budget permits cleaning only a small fraction of a massive corrupted dataset (\(k \ll N\)), deploy ActiveClean: prioritize cleaning records whose gradients with respect to the current model loss \(\nabla_\theta \mathcal{L}(h(x_i), y_i)\) are largest. This achieves \(95\%\) of full-dataset cleaning accuracy while inspecting less than \(5\%\) of records.

    Common Pitfall / Anti-Pattern: Unverified Programmatic Label Weak Supervision

    Using heuristic rules or LLM prompts for programmatic data cleaning without computing a Snorkel generative label model fails to account for correlated errors and multi-source labeling dependencies.

    💻 Production Implementation: Streaming Scaler and Confident Learning Pruner

    The following executable Python script implements an online \(\mathcal{O}(1)\)-memory Welford streaming scaler alongside a complete Confident Learning label error auditor.

    """
advanced_preprocessing.py
Frontier Implementations: Online Welford Stream Scaler and Confident Learning Label Pruner
"""

from typing import List, Tuple
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold

# =========================================================
# 1. Online Welford Streaming Scaler (O(1) Memory)
# =========================================================
class WelfordStreamingScaler:
    """
    Numerically stable online scaler maintaining exact rolling mean and variance.
    Memory complexity: O(d) for d features; Time complexity: O(1) per arrival.
    """
    def __init__(self, d: int):
        self.d = d
        self.count = 0
        self.mean = np.zeros(d, dtype=float)
        self.M2 = np.zeros(d, dtype=float)

    def update(self, x: np.ndarray) -> np.ndarray:
        """Ingests a new vector x and returns its standardized value."""
        self.count += 1
        delta = x - self.mean
        self.mean += delta / self.count
        delta2 = x - self.mean
        self.M2 += delta * delta2

        if self.count < 2:
            return np.zeros_like(x)

        variance = self.M2 / (self.count - 1)
        std_dev = np.sqrt(np.maximum(variance, 1e-8))
        return (x - self.mean) / std_dev

# =========================================================
# 2. Confident Learning Label Noise Pruner
# =========================================================
class ConfidentLearningAuditor:
    """
    Estimates class confidence thresholds and identifies corrupted annotations
    without requiring ground truth labels.
    """
    def __init__(self, cv: int = 5):
        self.cv = cv
        self.thresholds_ = None

    def find_label_issues(self, X: np.ndarray, y_noisy: np.ndarray) -> np.ndarray:
        n_classes = len(np.unique(y_noisy))
        pred_probs = np.zeros((len(y_noisy), n_classes))

        # 1. Out-of-fold cross-validated probability calibration
        skf = StratifiedKFold(n_splits=self.cv, shuffle=True, random_state=42)
        for train_idx, val_idx in skf.split(X, y_noisy):
            clf = LogisticRegression(solver="lbfgs")
            clf.fit(X[train_idx], y_noisy[train_idx])
            pred_probs[val_idx] = clf.predict_proba(X[val_idx])

        # 2. Compute class-specific self-confidence thresholds t_j
        self.thresholds_ = np.zeros(n_classes)
        for j in range(n_classes):
            class_mask = (y_noisy == j)
            if np.any(class_mask):
                self.thresholds_[j] = np.mean(pred_probs[class_mask, j])
            else:
                self.thresholds_[j] = 1.0 / n_classes

        # 3. Identify label errors: P(class k | x) >= t_k for k != observed label
        label_issues = []
        for i in range(len(y_noisy)):
            observed_label = y_noisy[i]
            candidate_classes = []
            for k in range(n_classes):
                if pred_probs[i, k] >= self.thresholds_[k]:
                    candidate_classes.append(k)

            # Flagged if highest confidence candidate contradicts observed label
            if candidate_classes:
                best_class = candidate_classes[np.argmax([pred_probs[i, c] for c in candidate_classes])]
                if best_class != observed_label:
                    label_issues.append(i)

        return np.array(label_issues, dtype=int)

# ---------------------------------------------------------
# Verification & Execution Benchmark
# ---------------------------------------------------------
if __name__ == "__main__":
    np.random.seed(42)

    # --- Part 1: Test Welford Streaming Scaler ---
    print("=== 1. Welford Online Streaming Scaler Verification ===")
    d = 2
    scaler = WelfordStreamingScaler(d=d)
    stream_samples = np.random.normal(loc=[100.0, 500.0], scale=[15.0, 50.0], size=(10000, d))

    scaled_stream = np.zeros_like(stream_samples)
    for i in range(len(stream_samples)):
        scaled_stream[i] = scaler.update(stream_samples[i])

    print(f"Total Stream Vectors Processed: {scaler.count}")
    print(f"Converged Streaming Mean:       {scaler.mean.round(2)} (True: [100.0, 500.0])")
    print(f"Converged Streaming Std Dev:    {np.sqrt(scaler.M2 / (scaler.count - 1)).round(2)} (True: [15.0, 50.0])")
    print(f"Normalized Vector (Last 100 avg): {np.mean(scaled_stream[-100:], axis=0).round(3)} (Expect approx 0.0)")

    # --- Part 2: Test Confident Learning Auditor ---
    print("\n=== 2. Confident Learning Label Error Pruning ===")
    n = 1000
    X = np.random.randn(n, 4)
    # True latent relationship: y* = 1 if x0 + x1 > 0 else 0
    y_clean = ((X[:, 0] + X[:, 1]) > 0.0).astype(int)

    # Inject 8% synthetic label noise (flipping binary labels)
    noisy_indices = np.random.choice(n, size=80, replace=False)
    y_noisy = y_clean.copy()
    y_noisy[noisy_indices] = 1 - y_noisy[noisy_indices]

    auditor = ConfidentLearningAuditor(cv=5)
    flagged_errors = auditor.find_label_issues(X, y_noisy)

    detected_true_errors = len(set(flagged_errors).intersection(set(noisy_indices)))
    precision = detected_true_errors / len(flagged_errors) if len(flagged_errors) > 0 else 0
    recall = detected_true_errors / len(noisy_indices)

    print(f"True Injected Errors:      {len(noisy_indices)}")
    print(f"Auditor Flagged Errors:    {len(flagged_errors)}")
    print(f"Correctly Caught Errors:   {detected_true_errors}")
    print(f"Label Noise Detection Precision: {precision:.3f}")
    print(f"Label Noise Detection Recall:    {recall:.3f}")

    Self-Assessment: ActiveClean Sampling Weight Convergence

    How does the ActiveClean framework use Stochastic Gradient Descent (SGD) with importance sampling to guarantee unbiased model parameter convergence when cleaning only a non-random subset of records?

    Reveal Detailed Solution

    Answer: ActiveClean uses Horvitz-Thompson Importance Weights: $\(w_i = \frac{1}{q_i}\)$ where \(q_i \propto \|\nabla_\theta \mathcal{L}(x_i, y_i)\|\) is the probability of selecting record \(i\) for human or automated cleaning.

    By weighting the cleaned gradient update by \(w_i\), the expected value of the sampled gradient is mathematically equal to the true full-data gradient: $\(\mathbb{E}\left[ \sum_{i \in \mathcal{S}} \frac{\nabla \mathcal{L}_i}{q_i} \right] = \sum_{i=1}^N \nabla \mathcal{L}_i\)$ guaranteeing unbiased convergence toward the optimal clean-data parameters \(\theta^*\).

    Self-Assessment: HoloClean Weak Supervision and Probabilistic Factoring

    How does the HoloClean framework combine denial constraints, external knowledge bases, and quantitative statistics into a unified probabilistic factor graph for automated data repair?

    Reveal Detailed Solution

    Answer: HoloClean models dirty data repair as Maximum A Posteriori (MAP) inference over a factor graph.

    Features, relational integrity constraints (e.g., denial constraints: \(\text{ZIP} \to \text{State}\)), and external knowledge base matches are expressed as weighted feature functions \(\phi_j(c)\). The joint probability distribution over candidate repair values \(c\) is: $\(P(C = c) = \frac{1}{Z} \exp\left( \sum_j w_j \phi_j(c) \right)\)$ HoloClean learns weights \(w_j\) via marginal maximum likelihood, finding the most statistically coherent repair that satisfies constraints with minimal distortion of observed features.
